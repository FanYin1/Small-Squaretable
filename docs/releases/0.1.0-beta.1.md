## 操作交接

配置在仓库根目录 `.env.beta`，权限 0600，已排除 Git 与 Docker 构建上下文。应用和数据分别位于 `squaretable-beta` Compose 项目及独立卷；既有业务 PostgreSQL / Redis 保持原状。

首次运营者单次邀请码保存在 `backups/beta/first-invite.txt`，有效期为生成起 24 小时。该目录权限 0700，文件权限 0600，已被 Git 与 Docker 忽略；不要将内容写入公开文档。到期后按部署说明重新生成。请本人在注册页设置密码并确认年龄，再用已注册邮箱运行 `first-admin`，退出后重新登录。不代替用户确认年龄或创建共享管理员密码。

完整安装、邀请码、提权、内容审核、充值、备份及回退命令见 [`部署手册`](../deployment/beta-release.md)。当前初始备份保存在 `backups/beta/database.dump` 与 `uploads.tar.gz`，运营者完成初始化后应重新备份。
