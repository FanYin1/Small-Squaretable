# User Persona 管理指南

## 概述

User Persona（用户人设）系统允许用户创建多个角色身份，在不同的聊天场景中使用不同的人设进行角色扮演。

## 功能特性

### 1. 基础信息
- **名称**: 替换聊天中的 `{{user}}` 宏
- **描述**: 注入到系统提示词，为 AI 提供用户背景信息
- **头像**: 在聊天界面显示用户头像
- **默认标记**: 设置默认使用的 Persona

### 2. 元数据系统
灵活的键值对存储，支持任意自定义字段：
- 年龄、性别、职业
- 军衔、所属组织
- 性格特征、外貌描述
- 背景故事、专长技能

### 3. 快速模板
预设常见角色模板，一键应用：
- **指挥官**: 军事指挥官设定
- **科学家**: 研究人员设定
- **飞行员**: 战斗机驾驶员设定
- **工程师**: 技术工程师设定

## 操作指南

### 创建 Persona

1. 访问 **用户角色** 页面
2. 点击 **创建角色** 按钮
3. 填写基础信息：
   - 名称（必填）
   - 描述（推荐填写）
   - 头像 URL（可选）
4. 添加元数据：
   - 点击 **快速模板** 应用预设
   - 或手动添加自定义字段
5. 设置是否为默认 Persona
6. 点击 **保存**

### 编辑 Persona

1. 在列表中找到要编辑的 Persona
2. 点击 **编辑** 按钮
3. 修改信息后保存

### 设置默认 Persona

1. 点击 Persona 旁的 **设为默认** 按钮
2. 创建新聊天时会自动使用默认 Persona

### 在聊天中使用 Persona

1. 创建新聊天时，选择要使用的 Persona
2. 系统会自动：
   - 将 `{{user}}` 替换为 Persona 名称
   - 注入 Persona 描述到系统提示词
   - 在聊天界面显示 Persona 头像

## 技术实现

### 宏替换机制

```typescript
// 角色卡中的宏
"{{char}} 向 {{user}} 敬礼，等待指挥官的命令。"

// 替换后
"Rina 向指挥官·艾伦敬礼，等待指挥官的命令。"
```

### 系统提示词注入

```
You are Rina.
[角色描述...]

[User Context]
蔚蓝星域联邦第七舰队指挥官，军衔上校。冷静理性，擅长战术分析...
```

### API 端点

```typescript
// 获取所有 Personas
GET /api/v1/personas

// 创建 Persona
POST /api/v1/personas
{
  "name": "指挥官·艾伦",
  "description": "...",
  "metadata": {...}
}

// 更新 Persona
PATCH /api/v1/personas/:id

// 删除 Persona
DELETE /api/v1/personas/:id

// 设置默认
POST /api/v1/personas/:id/set-default
```

## 最佳实践

### 1. 描述撰写建议
- **简洁明了**: 200-500 字为宜
- **关键信息**: 包含性格、背景、特征
- **避免冗余**: 不要重复元数据中的信息

### 2. 元数据组织
- **标准化字段名**: 使用统一的字段名（如 "age" 而非 "年龄"）
- **分类清晰**: 基础信息、外貌、性格、背景分开
- **适度详细**: 不要过度细节化

### 3. 多 Persona 管理
- **场景分类**: 为不同类型的角色扮演创建专用 Persona
- **命名规范**: 使用清晰的命名（如 "指挥官·艾伦" 而非 "角色1"）
- **定期清理**: 删除不再使用的 Persona

## 常见问题

### Q: Persona 和角色卡有什么区别？
A:
- **角色卡**: 定义 AI 扮演的角色（如 Rina）
- **Persona**: 定义用户扮演的角色（如指挥官·艾伦）

### Q: 可以创建多少个 Persona？
A: 没有数量限制，但建议保持在 10 个以内便于管理。

### Q: 元数据会影响 AI 回复吗？
A: 元数据本身不直接影响，但描述字段会注入系统提示词，影响 AI 的回复风格。

### Q: 如何在现有聊天中切换 Persona？
A: 目前 Persona 在创建聊天时绑定，暂不支持中途切换。可以创建新聊天使用不同 Persona。
