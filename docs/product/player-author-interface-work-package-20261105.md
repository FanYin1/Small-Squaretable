## 固定边界

本包整理现有玩家、创作与工程诊断入口，不改故事生成协议、推荐来源、记忆抽取、世界书扫描或模型参数。不新增页面级常驻侧栏，不继续群聊开发；创作仍使用既有角色编辑器和世界书编辑器，不新建编辑后端。

既有正文流式、回复下方的竖排推荐、直接行动与分支入口保持。冻结故事继续使用开局版本；不迁移旧档、不重放失败轮次、不修改原卡或生产数据。工具入口调整不会解决供应商所有控制格式错误，单轮输出边界仍以工作包 3 为准。

## 可见行为与影响范围

| 入口 | 本包交付行为 | 边界 |
|---|---|---|
| 聊天 → 阅读设置 | 字号设置；旧式会话保留情绪标签 | 移出参数调节、导出、记忆、诊断、额度等操作 |
| 聊天 → 更多 → 故事工具 | 按需打开覆盖抽屉，默认展示记忆、置顶消息、搜索 | 暗幕、正文 inert、Escape 和关闭后焦点返回；不挤压正文宽度 |
| 故事工具 → 诊断与兼容 | 默认折叠；本轮上下文诊断、页面文字估算、绑定与兼容说明 | 实际请求记录沿用包 2；估算不冒充供应商用量或完整上下文；旧档不补造开局诊断 |
| 故事工具 → 创作与设定 | 默认折叠；通往“我的角色卡”和世界书管理的入口 | 泛创作入口，不绕过所有权检查，不直接编辑当前故事冻结设定 |
| 冻结故事的工具 | 不展示未生效的旧式参数覆盖和通用成长面板 | 不改变服务器参数策略；不能用通用成长冒充该故事的状态 |
| 旧式会话的工具 | 保留旧调试、会话参数和角色成长；生成中禁用参数调节 | 参数与成长组件在请求打开时才挂载；不改变旧会话加载语义 |
| 聊天 → 更多 | 保留搜索、导出、重命名、删除、纠正与分支，补齐快照分享入口 | 原阅读设置中的快照入口迁移，未删除该能力 |
| 角色卡编辑器 | 增加折叠的编辑影响范围说明 | 新故事使用新作品；已冻结故事不被覆盖；未冻结旧式会话按原方式加载。玩家预览不代表模型/规则已执行 |
| 世界书编辑器 | “单本触发预览”及折叠范围说明；计时字段旁提示 Sticky/Cooldown 仅保存供兼容导出 | 预览读取已保存的单本内容和测试文本，不等同实际历史、多书组合或最终请求裁剪；保留已有字段值 |

当前上下文诊断入口由包 2 的“更多 → 本轮上下文诊断”迁移为“更多 → 故事工具 → 诊断与兼容 → 本轮上下文诊断”。没有新增请求诊断数据，也不修改其所有权、保留时间和脱敏边界。

工具抽屉切换到记忆/上下文诊断前，先释放上一抽屉的 inert 与滚动锁。工具、记忆、上下文诊断、置顶消息关闭后返回稳定的头部“更多”按钮；阅读设置返回自己的按钮。故事或账户/租户切换时关闭工具及相关面板，异步切换不会把旧账号的待打开面板带到新范围。
