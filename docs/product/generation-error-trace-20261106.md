# 生成错误记录与回溯增强

日期：2026-11-06（香港时间）。用户要求加强错误日志回溯和详细信息记录。对应 DEC-14/31/32/34、INV-01/02/04/05/08/09；在已发布四包基础上增加诊断，不改变原有正文/控制协议、模型输出额度、失败不确认及冻结故事边界。

## 本次交付

### 一条执行记录关联一次尝试

对已经完成所有权检查、通过重复请求识别的请求建立独立诊断编号。包含准备阶段失败和单人生成结果；识别为群聊后不记录群聊生成过程，不恢复群聊开发。

记录请求 ID、数据库生成 ID、用户/助手消息 ID、模型、开始/结束时间、总耗时、各阶段进入时间及关联提示词诊断 ID。阶段覆盖权限/设定/额度检查、保存输入、提示词组装、上下文检查、预扣、上游接收、用量计量、校验与保存、结算、保存后处理、结果持久化。没有执行的阶段不补造。

- `status` 是生成流程结果，`stateStatus` 是已有保存回执中的剧情状态；两者分别展示。即使之后结算失败，仍保留已保存的助手消息 ID 和已确认状态。
- `outcomePersisted` 记录生成结果落库是否成功；未创建生成请求时为 false，界面标明“未完成或不适用”。不将诊断写入成功等同于剧情提交成功。
- 首个观察到的错误阶段保留，finally 中结算/收尾不能覆盖它；原有错误处理和结算顺序保持。
- 普通消息配额拒绝补上稳定的 `QUOTA_EXCEEDED` 结果码，不自动重试。

### 具体错误证据

- HTTP 状态和安全错误分类；Anthropic 沿用已有错误分类和响应体读取状态，其他接口仅在可确定时给出 HTTP/异常类别，不猜测供应商拒绝原因。
- 上下文拒绝保存原因、所需/可用 token、总窗口和输出预留；未知 AppError 的任意 details 不复制。
- 输出字符数、SHA-256 指纹、结束原因、流不完整/截断标志、首片段和首段可见正文耗时；供应商 usage 有多少记录多少，不以估算补造 provider 用量。
- 原有 JSON 错误类别、UTF-16 偏移、长度、字符类别，控制标签不完整类型及长度，校验结果和兼容降级 warnings。
- 新增最多 12 个 schema 错误位置及固定错误类型，如 `steps.0.actionId / invalid_type`。只允许协议字段路径，未知字段替换为 `?`，不保留 Zod 原始报错、拒绝值或额外字段名。可选推荐/引导继续按原逻辑降级，不影响行动授权。
- 最多 8 个应用堆栈位置，只保留 `src|dist/server|core|db` 下的路径与行列号；不保存原始异常消息、URL、连接串或完整 stack。
- 服务端生成摘要日志带会话、请求、诊断及生成 ID、结果、阶段、状态码和耗时；性能日志增加同一请求/诊断关联。修正生成结果落库错误日志的参数位置，避免关联字段被错误对象吞掉；删除这条 WebSocket 链路中已有的用户输入和提示词预览日志。

### 访问与导出

入口：**聊天 → 更多 → 故事工具 → 诊断与兼容 → 本轮上下文诊断 → 生成结果与错误回溯**。

接口 `GET /api/v1/chats/:id/generation-traces` 复用认证及故事所有者/租户校验，`Cache-Control: no-store`。其他账号、其他租户、已删除故事均不可读取，管理员没有新增绕过所有权入口。

每轮可展开和导出诊断 JSON。导出包含当前会话 ID 及脱敏执行信息，不包含提示词、正文、控制原文、密钥或供应商错误原文；导出不调用模型或推进剧情。刷新失败清除旧展示，切换会话/账号或卸载丢弃迟到结果。提示词诊断编号在原明细中显示，可与执行记录对照。

## 存储与边界

- Redis 单独命名空间，按租户、所有者、故事隔离，最近 30 条，逐条 TTL 7 天；仍沿用实际请求提示词诊断的 10 条/24 小时独立策略。关联提示词明细可能先过期。
- 每条不超过 24 KiB、最多 32 阶段事件；读取和写入分别最多 32 个在途任务。写入不被生成流程 await，不在 Redis 重连期间排入新记录；读取超时 300ms。记录格式使用白名单 schema；坏记录单独跳过。
- 记录失败、容量保护有每分钟最多一次的固定类别日志，不输出 Redis 原始异常。没有新增数据库迁移，使用部署现有 Redis 持久化策略；不承诺独立审计库的永久保存。
- **只在请求退出 finally 时写执行记录**，不是实时任务看板。进程被杀、机器崩溃、Redis 故障或队列保护可能丢记录；已有数据库 generation_requests 保持原来作用。未创建记录不能推断成功。
- 非法认证、无权限、忙锁拒绝及重复请求不会生成这类故事记录；其他 HTTP、上传、后台操作、记忆任务完整生命周期不在本包范围。
- 不保存完整模型原文，因此不能还原历史错误原文；响应指纹只能用于比对，不能解码。未增加自动模型修复、重放或额外付费调用。
