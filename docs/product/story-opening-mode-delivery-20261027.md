# AD-3：原卡首次互斥模式选择

对应EXP-ADAPT、DEC-05/06/08/18、INV-02/08/09。完整审查另一份真实来源sans及其唯一绑定世界书，交付首次模式选择、条件赋值和一次性提交这一有限机制。本页不关闭AD-3、AD-5或任何父工作包；没有修改已确认产品决策。

## 本次开发后的实际效果

3081已部署本次实现。导入已审查的精确版本sans，执行“整理与兼容检查”后，新故事初始只显示“开局模式：未选择”，并提供`/剧情模式`和`/战斗模式`。推荐行动与自由输入沿用同一提交链路；直接命令可匹配行动，其他表述只能按现有意图确认流程处理，不能把否定、引述或提问直接算作选择。

完整保存后，剧情模式记录开局Lv0；战斗模式记录开局Lv19和开局地点“审判长廊”。两选项互斥，在本分支只能选一次；中断或尚未确认的候选不结算。刷新、重启与备份恢复保留结果；从选择之前另开分支可以改选，选择之后的分支继承原结果。

界面明确写为“开局Lv（不随经验更新）”和“开局地点（非当前位置）”。详情、开场、冻结兼容报告和模型提示均限定范围：击杀经验、后续等级、生命值、战斗裁决和地图尚未适配。没有展示虚构地图、价格、奖励，也没有把开局记录当作实时等级或位置。

同时修复实际原卡暴露的开场问题：作者推广封面被误当正文，详情页又固定预览`first_mes`。现在只有同时带明确推广标识与进入正文操作指引的封面才被分类为目录；详情预览第一个叙事开场。本卡显示备用剧情正文，作者原件保持不变；没有可用正文时不捏造开场。
