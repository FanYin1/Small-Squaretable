# 私人故事库视觉与交互改版

对应 DEC-03/14/24/25、INV-08/09，以及本轮用户要求：私人角色卡页面应适应探索体验，替换旧市场的视觉和操作组织。此交付覆盖私人库、卡片入口和私人详情，不关闭 EXP-02、EXP-ADAPT 等父工作包。

## 用户能看到的改变

- `/my-characters` 改为“我的故事库”，采用现有探索页面的纸色、墨色、金色强调和阅读字体，同时支持深色。导入与创作是明确入口，世界书、预设及模板收进“整理与创作工具”。
- 私人卡片使用独立组件，依次呈现封面、作品名称、真实简介、标签和操作。“进入故事”是主按钮；查看详情、编辑和更多管理各自独立。发布、导出、复制、删除可通过键盘操作菜单，不再依赖悬停覆盖层，也不展示市场收藏和下载热度。
- 手机使用横向封面与简介，压缩筛选和收藏夹的垂直占用，让正常内容的第一张故事卡及进入按钮出现在首屏。长标题截断、长标签省略、缺图降级和网格最小宽度共同避免横向溢出。
- 私人详情优先呈现简介、进入/续接真实存档、开场、场景与人物；长简介按需展开。编辑、介绍整理和兼容检查进入明确的次级区域，能力报告仍可查看。作品主人在此仍位于“创作”导航，私人分享状态与公开发布状态分别说明。
- 单个或多个文件统一通过既有服务端导入接口解析，显示逐文件结果。取消旧浏览器解析后直接创建角色的分叉，保留真实失败原因、服务器校验及原始字段处理。

原有收藏夹、批量管理、分页、审核状态、请求取消及手动重试继续接入真实接口。未增加虚构地图、数值或关系，没有改写旧存档冻结内容或机制支持范围。

## 实现位置

- `src/client/pages/MyCharacters.vue`、`components/character/PrivateStoryCard.vue`、`CollectionSidebar.vue`：私人库、卡片操作与统一导入。
- `src/client/pages/CharacterDetail.vue`：故事优先的私人详情与管理锚点。
- `src/client/components/layout/ExplorationLayout.vue`、`StoryNavigation.vue`：私人详情导航归属；其他页面保留原路由推导。
- 中英文 `privateLibrary` 文案；对应页面与新卡片的定向单元测试；真实部署检查脚本 `scripts/private-story-library-deployed-check.mjs`。
