# 个人故事库：有界读取与手动恢复

对应EXP-07D-LOAD、DEC-03/14。此前个人库定位卡片偶发超时没有完整网络证据，仍不能认定根因。本次源码确认的独立缺口是：列表GET没有读取截止时间，网络挂起时loading不会结束，现有错误提示及重试入口始终无法出现。

## 实现边界

- 全部作品和选定收藏中的作品读取使用15秒截止时间。包含等待响应和响应体解析；到时取消请求并结束本地等待，显示“读取故事库超时，请重试。已保存的作品不会因此丢失。”不当作空库，也不自动重试。
- 用户点击重试才发起新GET。第一页失败重读第一页；后续页失败保留已有卡片和下一页编号，重试同一失败页，不重复追加、不跳页。
- 新读取替换旧读取、切换收藏或离开页面时取消旧请求。既有请求版本检查仍保留，即使旧响应迟到也不能覆盖当前列表或弹出过期错误。
- 仅GET读取支持取消，不对创建/导入/保存/生成增加重试。取消客户端等待不承诺取消服务端已开始的数据库查询，也不删除服务端作品。
- 不改版式、封面或角色内容，使用现有错误提示区及重试按钮；错误时不显示“创建第一份作品”的空态。辅助收藏目录和其他页面请求不在本次截止时间范围内。
- 截图复核发现该入口沿用“刷新点数”文案，已改为“重新读取故事库”/“Reload library”，组件与浏览器检查均断言按钮名称；不再让用户误以为要调整点数才能恢复。

这改善“请求不返回时如何恢复”，不证明此前5秒浏览器定位超时一定由同一原因造成，也不关闭所有白屏、网络或加载稳定性问题。
