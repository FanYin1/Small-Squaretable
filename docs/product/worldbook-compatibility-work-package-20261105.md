# 工作包 1：世界书兼容与触发诊断

日期：2026-11-05。依据：用户确认两个项目对照后的四包范围，并指示开始。关联 DEC-10/11/12/14/27、INV-01/03/04/07/08/09。

## 固定范围与决定

本包只交付世界书导入/导出语义、扫描预算与窗口、统一扫描诊断和旧故事隔离。后续包 2 为实际请求提示词诊断，包 3 为单轮输出可靠性，包 4 为玩家/作者界面整理；本包不提前实现它们。Skill/MCP 是讨论过的候选，不属于这四包的交付前置条件。

参考本地 SillyTavern release 06bde939f（1.19.0）的枚举与字段行为；实现基于小小方桌现有服务，不移植第三方组件。

### 已落实的行为

- 数字逻辑采用 `0=AND_ANY, 1=NOT_ALL, 2=NOT_ANY, 3=AND_ALL`。内嵌、独立导入、导出和编辑器读法一致；已保存的字符串不自动交换。
- `scan_depth/scanDepth` 保留为条目列并可导出；0 表示不扫描文本（常驻条目仍独立处理），正数为消息窗口。独立文件、内嵌卡和已有的显式修复工具使用同一转换。
- v2 中 `exclude_recursion` 阻止被其他条目递归激活；`prevent_recursion` 阻止已激活条目的内容再触发其他条目。小小方桌已有 `recursive=false` 同样关闭向外递归。v1 语义保持原样。
- v2 把消息窗口、扫描迭代数、世界书选择预算分离。首轮计作一次迭代，默认 3 表示首轮加两次递归；不会因为模型窗口为 1M 就扫描一百万条消息。
- token 使用现有上下文保守估算：多语言估算与 UTF-8 字节数/3 取较大值；每条加换行后估算。不是供应商真实 tokenizer 或账单。宏展开一次用于计数与注入；被排除条目的宏变量变更不回写。
- 概率、延迟、预算过滤先于向下递归；概率 0 即使随机值为 0 也不通过；条目在一轮扫描内只抽样一次。按条目限制的历史深度在递归时仍然生效。
- 常驻内容延续原保留策略，允许超过世界书选择预算，并通过 `constantBudgetOverflow` 提示；模型最终总容量预检仍是硬边界。不把新的 2048 token 默认值变成截断关键规则的隐形上限。
- `sticky/cooldown` 保留原字段，明确标记暂不支持跨轮计时。未实现计时存储，也不称为完整 SillyTavern 世界书兼容。

### 新旧故事边界

新故事的世界书快照带可选 `scan` 配置：`version=2`、消息数、迭代数和 token 预算，参与 revision 哈希。运行时从快照取值；之后修改服务器配置不会改写已开始的 v2 故事参数。故事转移工具重新计算 revision 时也包含扫描配置；旧快照沿用原哈希方式。

没有 `scan` 的旧快照走冻结的 `worldinfo-legacy.service.ts`：保持 v1 的字符预算、原数字解释和窗口参数。这里只复制本仓库原扫描路径作为兼容实现，移除不再使用的测试器入口；不修补 v1 行为以免静默更改旧档。非快照旧式聊天也保留 v1。

发布后若已产生带 `scan` 的新快照，旧版本严格 schema 不能读取它们；回滚须使用保留 v1/v2 读取能力的兼容构建，不能删掉 `scan` 伪装成旧档。本轮未发布，因此尚无这一生产变化。

本包没有执行数据库迁移、旧卡修复或旧快照升级。修正新版扫描器不会自动纠正已被旧导入器转换成字符串的存量条目。既有只读导入审计仍可比较原始来源和绑定资料；差异需要复核，不能全库交换 AND_ALL/NOT_ALL。原显式修复工具的权限、指纹和事务约束保留；未运行它们。缺少原始来源时不得猜测原作者含义。

## 作者入口与诊断范围

世界书详情页新增“触发诊断”，调用与生成共用的 v2 扫描入口。返回注入项和逐条决定：停用、未满足关键词/窗口、角色筛选、禁止递归、概率、延迟和预算排除，以及暂不支持计时字段。

这是资料库中**单本世界书预览**：一条用户输入、当前编辑版本、没有故事历史/玩家宏/故事快照，概率每次抽样。界面明确说明；不能称为某个旧故事实际请求的复现。相同条目、消息、配置、宏上下文和随机结果下，共用引擎的结果应一致。查看真实请求由包 2 承接。

前端清空、修改输入、切换世界书或关闭后丢弃过期响应，防止旧结果覆盖新输入。预览只读取所有者资料，不保存变量、不调用模型、不更改故事。

## 配置

新故事捕获配置时使用以下服务器环境变量；未设置才使用默认值，非法配置明确报错。无需为了本包修改生产环境。

| 配置 | 默认 | 支持范围 |
|---|---:|---:|
| WORLD_INFO_SCAN_MESSAGE_COUNT | 10 | 1–1000 条消息 |
| WORLD_INFO_MAX_RECURSION_DEPTH | 3 | 1–10 次扫描迭代 |
| WORLD_INFO_TOKEN_BUDGET | 2048 | 1–100000 估算 token 的选择预算 |

单本扫描 API 可以显式传入对应参数；这只影响预览，不修改故事快照或模型上下文上限。延迟以传给引擎的历史消息数计算，不是付费轮次或状态事件版本；UI 单条输入不能模拟完整时间历史。

## 验收与发布边界

固定回归包括：四枚举真值、导入导出、0/正数深度、递归方向、预算和宏展开、概率 0、延迟、旧快照不变、版本路由、新快照配置冻结、未绑定拒绝、预览权限、排除原因、前端过期响应。

本地合成样例验证不等于四张真实卡长程游玩签收。未读取生产用户故事、未调用付费模型、未部署远程、未推送 GitHub；历史原文与角色卡内容未写入本文件。生产影响数量、真实卡长程表现和移动端人工视觉验收仍未完成，不替代既有 EXP/AD 验收。

不包含：inclusion groups、复杂概率评分、完整正则/宏语义等价、任意角色卡脚本、群聊、记忆算法重构、自动模型修复、历史请求重放、生产批量修复。
