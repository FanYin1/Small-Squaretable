# EXP-04D：自由行动、信息类型与人物知情

日期：2026-10-25。状态：04D工程工作包完成，已部署3081，见[实际效果与证据](../deployment/story-intent-04d.md)。原要求见 [backlog](backlog.md)，约束见 [DEC/INV](exploration-experience-baseline.md) 和 [EX-01至06](exploration-experience-contract.md)。完成范围为单卡行动确认和显式多人知情协议；技术实现不等于全卡真实模型质量或用户签收。

## 原要求与闭环

| 原要求 | 实现方式 | 必须验证 |
|---|---|---|
| 改写及菜单外合理行动 | 原生成调用返回版本1候选；核对后进入同一请求、版本、事件与事务链路 | 改写、自由探索、错误理解、过期候选、篡改来源、重放 |
| 否定、复合与澄清 | 区分执行、自由探索、拒绝；拒绝和执行混合时先澄清；复合规则逐项校验 | 不买而问价、条件不明、多动作资源不足、原子回滚 |
| 拒绝/传闻不成为资产 | 主张、意向、推测、叙事见闻、表达偏好独立于规则确认状态 | 金币传闻不加余额；拒绝不买票；类型和来源可查看 |
| 两个选择有依据的后果差异 | 仅冻结作者规则能改数值，候选不接受任意数值补丁 | 两个隔离故事的不同有效选择确实改变事件与状态 |
| 秘密不进入无权人物上下文 | 新多人故事显式选择听众；原文、事件、检索、整批摘要过滤 | 甲私聊、乙提问、甲公开发言、甲私聊续接、重启和草稿恢复 |
| 与既有交付连续 | 保留04C事务/停止/重放、冻结内容、账单和原始历史 | 原生恢复回归、实际3081升级演练和部署核对 |

## 行动协议

原生成响应可在正文后附加 `<story-intent>` 数据。传输阶段不显示协议正文；完整响应经过严格结构、大小、规则ID和原文引用校验。无效候选不更新资源，界面说明无法形成有效理解。普通文本回应仍可阅读，不伪称已经产生结构化候选。

2026-10-28补充引用处理边界：行动步骤仍须逐字匹配玩家输入，并验证可用规则ID；结构错误或无效步骤仍拒绝。结构有效的辅助记忆条目若无法逐字匹配对应说话人的原始文本，只丢弃该条，不用模糊匹配或去除Markdown来认可引用，也不因此阻断其余有效的解释、澄清或行动候选。候选正文中的人物陈述仍不晋升为记忆；过滤后没有步骤和记忆的空候选仍拒绝。真实回复中省略加粗符号的记忆引用触发了原有整体拒绝，故调整这一故障边界；不是放宽行动或奖励权限。

候选与程序生成的核对说明一起写入已有消息JSON，绑定原输入和提交后的状态版本，不增加后台理解调用。新增正常0051/beta0011迁移，为事件增加 `proposed` 状态。候选不累计到确认事件的记忆任务；无效结构记为未确认。玩家点击“确认并继续”是一次显式续写，沿用原生成计费，不静默重放。确认时重新验证存档、来源消息、完整状态、原输入、版本和每一步规则前置条件。不同版本、跨故事、篡改输入、无效规则或澄清对象均不能执行。

真实供应商样本发现：即使JSON正确标记为候选，前面的正文也可能提前描述玩家已经行动。因此待理解的自由输入先缓冲本轮正文，结构解析完成后，候选只展示程序生成的核对说明与结构化步骤；模型提前行动的正文不进入玩家已确认历史、后续提示或摘要。这会延后首次显示正文，但避免将“待确认”仅作为事后提示。已选定规则或已确认候选的续写仍流式显示；停止片段保留并标为未完成，不提交后果。

候选不是事实，模型只能提出可核对理解。数值后果来自冻结的作者规则；菜单外探索可以确认叙事参与，没有机制依据时不会猜造扣款、奖励、地图节点或属性。已有精确行动保留直接执行路径。通用确认协议首先用于单卡故事，多卡故事沿用叙事生成并新增人物知情范围；多人原生规则仍不支持，不能称为任意角色卡机制等价运行。

信息类型保存说话人、原文片段和所属事件。主张保留“未证实”，意向保留“未执行”；叙事见闻仍是有来源的文字解释，不能升级为规则确认资产。界面可以返回原始消息。语义是否忠实仍需真实模型样本验证，不能用JSON结构验证替代。

## 人物知情协议

新多人故事输入区区分公开交谈和单独对某人物说话。`@`只是选择回应者，不隐式改变知情范围；服务端校验听众属于冻结名单。私下输入与回复保存 `storyAudience`，回复提交必须与来源范围一致。省略属性的历史消息按原公开语义处理；格式错误的显式属性不可读取，不回填猜测历史秘密。

私下续接只能使用覆盖本轮全部听众的材料。公开生成不接收私下材料，即使当前说话者本人知道；这是保守的防止无意泄露措施，不是完整NPC自主保密/主动透露模拟。用户主动在公开输入中重新讲述的信息成为新的公开来源，不改写私聊历史。

派生检索按整个抽取批次的来源范围校验，不只检查模型列出的单条引用。摘要同样核对全批原文；缺来源或无有效链接的旧派生记忆不进入受保护的多人上下文。情绪派生尚无来源权限，受保护多人提示不注入此类情绪材料。卡片和世界书仍按冻结角色各自绑定加载；未标记的作者文本不承诺自动识别秘密。

私下与公开草稿使用不同存储键，刷新恢复听众时不会把私下草稿放入公开输入框。手记仍是故事共享背景，界面提示不要写私密内容。玩家作为存档所有者可阅读全部自己的对话；这里隔离的是人物生成上下文，不是多人真实用户之间的授权。

## 验收记录规则

单元测试、受控模型的真实接口/数据库/浏览器、真实供应商语义、部署构建和人工签收分别记录。最终338项测试（29新增、309回归）、13组04D+16组04C副作用+6组恢复组合检查通过；最终展示规则另复查14项。71表迁移保留原数据，3081已部署04D镜像并通过重启、四张实际页面和构建摘要核对，beta0011累计12项。原要求逐项映射及证据见[交付记录](../deployment/story-intent-04d.md)，不据此关闭完整产品或人工验收。

累计模型额度沿用450,000授权。本轮两个真实短样本共3,135 token；已知累计439,863，旧未回执预留6,591，合计446,454，剩3,546。原始结果见[真实模型记录](../deployment/evidence/story-intent-04d-model.json)：改写购买理解正确；拒绝/传闻/菜单外探索的结构正确，但正文提前行动缺陷按上文修复，原始响应经真实本机API/WS/数据库重放验证，不进入玩家历史或确认记忆。不是完整真实游玩、全卡质量或用户签收；不得再以旧剩余额度调用。付费脚本使用单次全局锁，重新运行需先重新核对累计账目，不能换输出路径重置预算。

OPEN-01纠正/分支、OPEN-02默认推荐交互、OPEN-04完整记忆和OPEN-07输入模式不因此关闭。候选核对是新增事件前的确认，不能用于改写已确认历史。
