## 固定行为

- 原卡、绑定书与已有故事不改写。每次整理保存输入修订号、编译器版本、来源摘要和不可变结果；新故事冻结结果，分支复用父故事版本。
- LangGraph 仅组织“收集、检查、编译、完成”。数据库任务及租约是恢复依据，故事事件仍是数值真相，不新增模型自由修改状态的通道。
- 取消、超时恢复和重试不得让旧工作进程提交；源内容变化后结果标记过期，不自动套用。重试产生新任务，保留旧结果。
- 作者现有介绍/用户修改优先。缺失介绍仅采用已实现的安全开场摘录；本轮不以确定性摘录冒充模型整理。
- 仅处理当前卡明确绑定且启用的资料。支持显式 `squaretable-rules-v1` JSON 代码块，内容为已公布的 exploration v1 规则结构：赋值、增减、简单条件、一次触发。它是新增的作者声明入口，不宣称既有第三方卡已经使用此结构。
- 外部控制块、其他已识别机制、多个声明或与原生规则并存，均不自动启用外部规则。无声明保留“未支持”，规则无效保留“需修复”；绝不从自然语言价格、模型回显或背景资产猜出可执行规则。
- 适配成功只表示该有限声明通过校验，不表示卡片其他机制完整兼容。界面在开始前给出状态与限制，旧故事不静默升级。
- 本轮确定性工作流不调用付费模型，不使用个人点数。模型提案节点须另接工程额度预留、实际用量和未知失败占用，不能借此直接开放无额度 agent。

## 验证与尚存缺口

必须验证来源范围、无效/重复声明、原生与初始化冲突、取消/重试/租约竞争、源变更、任务授权、开局冻结、状态恢复及分支回放。真实《蔚蓝星域》与 t1/t2/t3 继续明确列出未支持机制。

新增抽样 1,480 文件中 1,428 可解析、48 失败；发现的 24XX 升级费/重投费用与掷骰、任务生成、船员及装备机制相连，不能将单一扣款冒充完整交易。真实固定规则样本与真实模型整理仍为 AD-3/5、AD-1/4 的未完成项；不以本契约缩小原验收要求或整项勾选。
