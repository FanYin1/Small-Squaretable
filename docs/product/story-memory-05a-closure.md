# EXP-05A 全链路记忆收尾

2026-10-25 开始。依据原 EXP-05A、DEC-07/08、INV-01/03/09，以及 EX-07/10/12；不以新增的小项替换父任务要求。

最终状态（同日）：工程收尾完成并部署3081；[结果及逐项证据](../deployment/story-memory-05a-completion.md)。新增11组记忆检查和真实续写请求复核覆盖本轮缺口；真实100+5轮使用05B历史证据，未重复冒充本轮真实模型调用。

用户可见目标：同一次体验的经历、约定与表达偏好有来源，离开回来仍可复用；其他存档、其他账号和无权人物不会混入；来源失效后不继续把旧派生内容当作可信记忆。

本轮发现并修复的缺口：旧删除接口仅凭记忆ID删除；旧提取入口未核对故事归属且可绕过新故事任务；无chatId的旧查询/清理覆盖所有存档；04D事实过滤核对知情但未复核原文指纹；精确去重未包含信息类型；单人入口遗漏知情过滤标志；偏好完全依赖相似检索且会被普通容量淘汰。这些均在05A内闭合，没有另造需要用户逐次批准的小任务。

验证必须区分受控抽取、真实数据库/HTTP、已归档真实模型以及人工质量。新增真实模型调用默认0，累计授权剩余3,546不能重置。原文语义抽取仍可能出错；有界检索不承诺所有历史永远进入上下文。纠正/分支、全文风人工签收及OPEN不由本轮代签。
