## 角色卡与世界书

连续记忆后续补充（2026-10-24，源码未部署）：[分批摘要生命周期](story-summary-lifecycle.md) 在来源核对和容量约束下为续写提供历史材料，不能修改本协议的确认状态、事件或资产；完整人物知情与事实裁决仍未完成。

角色卡是进入体验的入口。开始时保存身份、角色正文和作者明确绑定的世界书快照，生成读取此次快照。编辑来源只影响新故事；删除来源不会要求旧故事临时猜配资料。空绑定不加载全局资料。

普通卡使用自由叙事、原文历史、历程及此次笔记。只有明确提供本协议的卡才显示数值、推荐行动和地图。第三方脚本原样保存在私有卡片快照中，新故事不执行其外部界面；插件、小游戏、任意 HTML 状态栏不等于已支持。

角色详情说明这张卡的能力；创作编辑器提供“探索行动与状态”JSON 输入与格式验证。世界书可以是背景、常识、概念、规则的补充，不要求玩家额外选世界。

## 原生协议

位置：`cardData.extensions.squaretable.exploration`。两个完整原创实例见 `src/types/story-examples.ts`。编辑器保存空值将使用普通叙事模式，不自动创建任何面板数值。

```json
{
  "version": 1,
  "fields": [
    { "id": "coins", "label": "随身钱款", "type": "number", "initial": 20, "min": 0, "unit": "枚" },
    { "id": "permit", "label": "通行凭证", "type": "boolean", "initial": false }
  ],
  "actions": [
    {
      "id": "buy-permit",
      "label": "花 20 枚钱购买通行凭证",
      "intent": "act",
      "once": true,
      "requires": [{ "field": "coins", "operator": "gte", "value": 20 }],
      "changes": [
        { "field": "coins", "operation": "add", "value": -20 },
        { "field": "permit", "operation": "set", "value": true }
      ],
      "outcome": "玩家支付20枚钱并取得通行凭证，尚未进入目的地。"
    }
  ]
}
```

- 字段支持数字、文字、布尔值；`null` 表示未知，不等于零。`min/max` 限制数值范围。字段的 `visible/visibleWhen` 控制概况列表显示；作者另行声明的地图按节点可见条件显示，不因原始位置字段未列入概况而隐藏已知地图上的当前位置。
- 条件使用字段 ID 与 `eq/ne/gte/lte`。未知值不会满足与已知数值的比较。
- 行动支持观察、交谈、行动、前往；`requires`、资源范围和 `once` 决定可用性。`changes` 支持明确赋值和数字增减。
- `aliases` 仅是精确文字别名，不是模型意图分类。自由提问、否定或复合句不会因为含有购买关键词就扣资源。
- `map.locationField` 指向位置字段，`nodes` 定义地点、连接和可见条件。查看地图不移动；行动只能到达当前连接且已可见的地点。
- 协议限制字段、行动、条件和内容长度。ID、类型、引用、重名或地图连接错误会阻止新开局并给出错误，不使用半有效状态。
- 2026-10-25补验：新作者配置的比较条件须与字段类型匹配，数值边界只允许有限数字；既有冻结快照保持原解析兼容。状态面板和生成准备分别使用完整的只读可重复读事务；提交时仍校验版本。较早状态依据可按事件ID直接读取，服务器核对账号和故事归属，无需逐页扫描历程。证据见 [04A/04B收尾](../deployment/story-state-action-04ab-completion.md)。
- 当前结构化规则支持单卡故事；多角色普通叙事保留固定开局阵容。中途增减角色会改变版本依赖，暂不开放。

## 单轮提交

推荐项明确分为“填入输入框”和“执行”。前者不发请求，也不覆盖已有草稿；后者提交行动 ID 与所见版本。两种入口共用现有 WebSocket 生成、费用预扣和请求去重链路。OPEN-02 仍等待使用反馈，未默认判定其中一种交互为最终方案。

服务器先检查所有权、当前版本和行动条件，再生成正文。完成时在数据库事务内锁定状态行，同时保存助手原文、事件、字段变化及新版本。重复请求不重复扣剧情资源；不同进程竞争同一版本最多成功一次。停止留下的片段有中止标记，不提交行动效果。已进入保存事务的完整结果不能再通过停止请求改写为未发生。

行动版本/可用性/前提校验失败不允许复用旧参数直接重试。前端保留未确认草稿，移除未接收的临时消息；请求结束后重新读取状态，用户再次确认后以新请求提交。已被接收的用户消息保留。

经历断线恢复的生成结束后，客户端重新读取最后一条已保存消息，补齐流式传输遗漏的正文；读取失败会明确提示重新打开故事核对，不自动重发行动。提交回包丢失、重放、双标签冲突和原生单卡生成中途重连的验证见 [恢复检查](story-recovery-verification.md)。这些是源码及隔离构建行为，尚未部署至3081。

有内容快照的故事不执行助手正文里的ERA变量写入；旧故事仅在完整回复后保留该能力。单聊与群聊都保存停止片段的中断标记，不据片段执行ERA、人物成长或助手情绪/记忆派生。派生失败不否定已经保存的回复；新版本故事的持久抽取重试已补源码，见下文，旧故事变量事务仍未完成。

模型正文是叙事表达，不能直接写状态表。作者的 `outcome` 与已确认状态进入生成上下文；实际模型仍可能违背约束，必须另做剧情质量验收，不能用受控模型测试证明文字绝对一致。

新故事不开放独立编辑、删除原文或旧式回滚，以免产生正文与状态不同步。整体删除仍可用。这个保护不构成 OPEN-01 错误纠正、重写、分支方案的定案。

## 连续性与出处

2026-10-24页面补充：[玩家记忆进度与原文依据](story-memory-player-view.md) 区分手记、批次整理状态和实际保留条数；可阅读经归属/状态/摘要校验的输入与回应。未分级派生文本不直接展示，读取失败不宣称整理完成。依赖0048/beta0008，当前为源码及隔离验收，未部署3081。

2026-10-24源码补充：[上下文容量与输入恢复](story-context-budget.md) 已保护固定材料、最新整轮和置顶整轮；超限明确停止，原文/状态/笔记不变。取回文字仅追加草稿，不自动重放行动。此为生成预算和页面错误恢复，不代表自动摘要或完整长程记忆验收，尚未部署3081。

- 开局快照：身份、角色正文、绑定世界书，数据库禁止覆盖。
- 已确认事实：独立状态表、单调版本、字段对应的事件依据；不依赖模型上下文窗口维持余额或位置。
- 经历：每轮保存原始输入、回复、状态变更和停止状态，支持分页追溯及读取原文。
- 此次笔记：线索、未完成事项、表达偏好；仅供该故事后续生成使用，不等于状态裁决。最多20条、总共4000字符，删除后不再加入新提示。
- 派生语义记忆：检索、去重、配额清理按故事隔离；新故事记忆不自动升为全账户记忆，不参与旧全局聚合。删除故事同时删除其派生记忆。
- 持久抽取任务：0048/beta0008之后新提交的确认事件按故事/角色累计，每五次形成任务；中止片段不参与，进度/抽取检查点可跨重启恢复。来源与版本校验通过后，记忆、向量、出处及完成状态原子提交；失败有上限，受控重放保留历史，来源改变不能直接重放。见 [完整边界及证据](story-memory-durability.md)。该迁移尚未部署3081，不回填旧历史。

原始历史仍是可查依据。近期事件摘录和人工笔记进入后续生成；自动提取是辅助材料，失败不使已经提交的正文与状态失效。百轮状态持久化测试不能代替百轮真实模型对白风格测试。

非空恢复演练已覆盖原文、已确认/中断事件、笔记、有原文来源的合成记忆及向量，恢复后检索和继续行动通过；删除后的迟到记忆写入与行动提交被拒绝。见 [非空恢复记录](story-nonempty-restore-verification.md)。后续已补可信源库的旧备份删除重放及新故事持久抽取检查点恢复；这是实际服务/仓储及隔离数据库证据，不包含真实模型、HTTP或页面验收。独立灾备、完整可携带导出与整体记忆生命周期仍未完成。

自动记忆抽取过滤带 `stateStatus: interrupted` 的消息，包括后续批次读取的历史片段；未标记的历史消息不作推测性回填。完整摘要/派生生命周期仍按EXP-05B验证。

旧故事使用新阅读外观，但继续其原有数据语义，不伪造开局快照或历史状态。要体验原生状态闭环，应从角色卡新开一个故事。
