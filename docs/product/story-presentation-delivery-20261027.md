## 已实现的行为

LangGraph收集→选择→校验：作者/用户已有有效介绍优先，直接保留、不调用模型；缺失时只向模型提供公开叙事开场中的有限段落，模型只能返回一个候选ID或不选择。隐藏人物设定、世界书、系统提示、脚本和控制内容不作为介绍资料发送，不允许模型补写事实或拼接开场。

单段8～500字符，最多32候选及约15.5 KiB序列化资料，轮流取不同开场；输出明确记录未入选候选数。公开原始开场超过50个、单项64,000或总计256,000字符时整体拒绝，不截断原文后声称完整支持。场景摘录仅供展示审核，不能当作整卡概要或实际玩法。

产物严格记录角色ID、来源修订、编译器、原始开场摘要、标准化展示文本位置及候选覆盖。保存后重新读取原卡、重建候选并逐项核对；过期、伪造文本、位置/摘要/覆盖篡改均拒绝。保存产物不改原卡、数据库、个人点数或任何故事。

## CLI与私有材料

```bash
node scripts/story-presentation-check.mjs inspect --card <png/json> --output <new-private.json>
node scripts/story-presentation-check.mjs draft --config <gateway.env> --card <png/json> --output <new-private.json>
node scripts/story-presentation-check.mjs verify --card <png/json> --draft <saved-private.json> --output <new-private.json>
```

文件最多12 MiB，使用网页共享解析器；输出目录700/文件600且拒绝覆盖。只有draft可能调用真实模型，必须通过[共享工程预算入口](../deployment/engineering-model-budget.md)，不接受供应商直连配置。输出最多512 token、60秒超时、无自动付费重试。verify没有网络调用，另验证原文件SHA-256。

本批真实原始回执生成早于CLI新增原文件摘要字段，未改写原始回执以通过新命令；它们通过服务端来源复验器及调用前后原文件摘要核对。新增CLI的保存→复验路径另以合成资料验证。私有回执在`backups/exploration/presentation-20261027/`，不在公共文档发布第三方卡正文。
