# 行动提交与原始输入绑定

对应EXP-ADAPT的AD-3前置正确性，落实DEC-05/06/08/18及INV-02/05/08/09。本次不扩大可转换机制，不关闭AD-3或AD-5。

## 实际效果与原因

此前只有咔咔身份规则在提交时核对准备输入与已保存玩家消息。其他行动虽然检查所属故事、用户、听众、状态版本和请求幂等，仍可能把准备好的购买或选择绑定到另一条拒绝消息。本轮在隔离PostgreSQL中先复现了该问题；这是内部提交一致性缺口，未据此证明存在外部可利用路径。

现在所有新回合提交都必须逐字匹配准备时的输入。错绑、缺失输入或内容变化返回`STORY_SOURCE_UNAVAILABLE`；事务不写入回复、事件、数值或来源。正确输入仍沿用原有状态版本锁、原子提交和幂等流程。游戏资源与平台点数是两个独立系统，本轮没有增加真实平台扣费条件。

候选行动确认也受同一约束：保存的是拒绝或改选消息时，不能提交另一份已准备的确认。回归覆盖拒绝后原候选仍可正确确认。已完成请求的原始回执继续优先返回，历史存档不回填、不重新解释，原角色卡及绑定规则不修改。
