# 自动介绍整理队列：本机内测交付

对应 EXP-ADAPT AD-1/4 与 DEC-19；[八项固定契约](story-presentation-queue-contract.md)的有限工程实现、隔离验证和真实短测完成。不是整个适配父任务完成，也不是公网常驻运营服务。

## 本次开发后的实际效果

新建或导入私有角色卡时自动保存介绍整理任务，和角色及内嵌世界书同事务提交。作者有效介绍优先；没有适合的公开候选则跳过，公开卡不自动整理，历史卡不回填。详情新增“介绍整理”状态区，可先体验原卡，也可停止采用；页面读取不收费。

运行有界预算 worker 后，任务自动领取、通过既有 LangGraph 选择一个有来源的公开段落、保存结果并采用。页面轮询完成状态后刷新介绍，用户不用再手动复制离线回执。持久任务与网关使用同一 dispatch ID，重复请求在供应商调用前拒绝。

发出后结果未知不会按租约重跑；收到的有效结果先保存，再与采用版本同事务完成，崩溃后可以不联网恢复。取消、手写介绍和公开性变更阻止迟到采用，已产生的用量仍记录，不能把取消当免费。原卡、旧故事和用户点数不被整理修改。

**当前没有常驻付费 worker。** 本次真实测试批次已关闭、网关停止，新导入缺介绍的卡会显示等待受额度约束的服务，而不会无限消费工程预算。管理员可按[操作说明](../deployment/story-presentation-queue.md)启动限定账户、最多20任务/3600秒的工程 worker。实际3081数据库连接已做零任务验证，无模型调用。
