# 玩家可见的记忆整理进度与原文依据

日期：2026-10-24。属于 EXP-05A/05B，关联 DEC-07/08、INV-01/03/09、EX-07/10。延续已确认的故事独立记忆方向；不改变 OPEN-01至07，不把整理状态等同于完整摘要或剧情质量。

## 页面与行为

后续摘要补充（2026-10-24）：[分批摘要](story-summary-lifecycle.md) 已在成功任务检查点保存并按预算用于默认续写。本接口仍不返回摘要正文；保留记忆条数只统计有效事实来源链接，不统计摘要，也不表示此批已进入本次生成。该补充未部署3081。

探索页“此次游玩 → 记忆”现在分为“自动记忆整理”和“我的手记”。原手记读写继续沿用已有接口；新区域显示此次故事的真实持久任务状态：等待整理、正在整理、等待重试、整理未完成、已整理。已过期的执行租约显示“等待恢复整理”，避免假装仍在工作。

统计数字的单位是批次，不是记住了多少条事实。每位角色累计五次完整确认回应后形成一批，界面分别显示未满批的累计进度。已成功批次显示当前仍有有效来源链接的辅助记忆条数；成功但零条保留不等于原文丢失，也不保证该批所有细节都被记住。同一条去重记忆可能关联多个批次，不能把各批条数相加当成全故事唯一记忆总量。

每批“查看本批依据”可以展开对应轮次，分别阅读玩家输入与角色回应，复用已鉴权的原文接口和“历程原文”窗口。这是批次来源，不是逐条派生结论的逐字引用界面。未完成整理不触发剧情重试，也不会修改正文、手记或确认状态。

首次打开记忆区、当前故事生成结束/版本更新时读取；后台任务可能稍后完成，玩家可使用“刷新进度”。未增加定时轮询。请求失败明确提示，并标明保留了上次读取结果；不会把失败画成“没有记忆”。更早的记录分页读取，刷新第一页会重置已展开的分页集合。

切换账号/租户/故事、切换资料标签或离开页面时，旧请求不能覆盖新页面；分页与刷新交错时同样丢弃迟到结果。手机沿用可展开资料窗口，Escape收起并将焦点还给入口。补充说明默认收起，让进度与原文操作优先出现；无全局进度条或虚构的完成百分比。

## 读取协议与保护

只读入口：`GET /api/v1/chats/:id/story-memory?before=<job UUID>`。显式关闭缓存；先校验故事所有者与租户，再在同一个可重复读事务读取任务、进度与来源。旧故事返回 `supported: false`，明确表示不覆盖；不伪造历史回填结果。

每页最多20个批次，按建立时间及ID倒序分页。游标必须属于当前故事；非法/不存在/其他故事的游标不泄露内容。游标比较保留数据库时间的微秒精度，避免同一毫秒的批次跳项。汇总统计针对完整故事，不随当前页变化。

角色名称来自冻结的故事快照。来源必须同时满足：同一故事、对应角色、确认事件、合法用户输入与助手回应、正确的请求号/状态版本、非中止输入。已有来源内容指纹时还核对原文的SHA-256摘要；任一不符则不返回该批来源按钮及保留条数。实际读取到的原文只用于服务端校验，不附加在进度响应里。

接口不返回自动抽取正文、系统提示、世界书、原始错误、租约令牌、来源摘要或重放记录。尚未建立逐条派生文本的玩家可见性规则，因此本次提供处理状态、保留计数与可读原文入口，不将未分级的派生内容直接展示给玩家。没有用户侧重放按钮；失败任务仍按既有运维重放流程处理。

## 验证与复现

- `npm run check:story-memory`：隔离数据库的完整迁移/非空恢复及持久任务检查，新增玩家读取、归属隔离、来源校验、时间精度分页、删除及旧故事边界。
- `npm run check:story-memory-ui`：构建当前前后端，在回环服务与一次性PostgreSQL/Redis执行真实HTTP/WebSocket/Chromium检查。五轮正文由受控模型生成，真实提交产生一批任务；失败、过期租约和成功保留计数由明确标记的数据库夹具切换，不能把该页面检查算成真实抽取模型质量。
- 定向单元覆盖接口鉴权/参数、账号与故事切换、卸载/分页/刷新竞态、读取失败、来源按钮及旧档说明。浏览器故障场景只中断请求，不伪造成功响应；正常限流保持启用。

独立机器记录见 [玩家记忆读取验证](../deployment/evidence/story-memory-player-view-verification.json)。历史持久任务与上下文容量报告不改写为本轮结果。

实际结果：5文件67项定向单元、34项持久记忆/玩家读取数据库检查（其中13项为本次新增）、19项恢复行为、14项证据守卫及2项损坏探针通过。7组真实API/浏览器检查、类型检查和前后端生产构建通过；定向lint零错误，保留1条既有警告。已检查1440px失败提示与390px原文操作截图，手机视口下实际点击原文、关闭窗口、Escape收起和焦点返回通过；一次性容器已清理。未运行全量单元、真实手机或真实供应商长对话。
