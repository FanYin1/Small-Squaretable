# AD-3：有来源角色回合计数器

对应DEC-18/27、INV-02/07/08/09。接续规则线索检查，目标是让一个真实原卡机制进入持续状态，而不是继续添加诊断后称玩法完成。

## 样本与语义边界

本地角色库的 `kakaa.png` 经共享PNG解析器读取。原文件SHA-256为 `f11040eeb4ac883009ebb51cb9d3b1a2702f36da19d3b9a9600aa218d57c411e`。不把原卡或整本书复制进仓库。

人工检查完整角色字段、唯一内嵌书的三个条目、开场及扩展后，选取“仪式”：力量第一次从0开始，每次对话后加3。归属是咔咔，而非玩家。原卡没有提供该力量到伤害、战斗胜负或玩家属性的计算关系，不根据同名游戏常识补造。

实现将“每次对话后”落实为平台**完整保存的一轮已确认回应**。开场不计；普通表达、澄清及已确认行动完成后计一次；候选行动仅为确认界面，不计；确认后完成计一次；中断、错误协议、失败和重复回执不计。这是明确披露的平台轮次约定，不声称与其他聊天前端的消息计数完全等价。

## 转换边界

- 这是已审查精确版本的确定性适配，不是通用自然语言理解或任意脚本编译；模型没有决定状态值。
- 全部有效卡字段、嵌套字段、开场、扩展、对外描述、绑定书名称、三条正文和映射后的触发设置共同参与指纹；仅接受无模板或数据库内置的`default`模板标识，其他模板、多卡、多绑定书、禁用条目或来源变更均拒绝。
- 仅排除不参与运行的原始导入归档及数据库标识/时间。绑定条目排序按正文规范化，避免同优先级条目的随机数据库ID影响匹配；仍核对每条的位置和设置。回执保存实际来源下标与正文摘要。
- 不运行任意JS，不向原件插入平台声明。产物保存在检查回执，新故事原子冻结；原卡后改不会升级旧档。
- 冻结产物只允许已审查的固定效果标识、字段、初值和来源摘要组合。普通旧声明不获得自动结算能力。
- `kakaa-ritual-v1`的计数语义是冻结契约。后续若改变触发边界或计算方法，必须新增效果版本，不得修改v1后让旧存档悄悄采用新规则。

## 运行与展示

沿用现有故事事务和事件表：完成后原子写入正文、变化前后值、来源事件及状态版本。重复请求在已有回执处返回；中断、候选和错误协议不应用自动效果。安全整数范围外或损坏值拒绝结算，不静默舍入。

分支按冻结效果重新计算每轮变化并与历史事件比较，不能只拷贝最新值。原档与分支分别继续，刷新和重启读取数据库状态。概况显示“咔咔的力量（角色）”，不新增虚构行动或地图；详情、开场及冻结兼容报告解释支持边界。

没有新增数据库表或迁移，但新增的冻结产物含`turnEffect`。旧应用不认识这个结构：一旦产生新效果故事，不能直接换回旧镜像继续写入这些故事。回退需使用兼容读取实现，或维护窗口下按备份恢复应用与数据，并明确备份之后的数据范围；不能将“迁移数没变”理解为任意降级安全。

## 固定验收

| 编号 | 验收要求 |
|---|---|
| RT-01 | 原始PNG经网页共享导入、持久检查、开场冻结后初值0；旧档无自动补造 |
| RT-02 | 0→3→6→9；并发重复提交只加一次；中断、错误协议、候选不加；确认后加一次且过期确认拒绝 |
| RT-03 | 分支还原前缀并独立推进；重启前后状态、来源和冻结效果一致 |
| RT-04 | 桌面与手机详情/概况显示角色归属和实际数值，冻结报告不宣称已适配条件交易等其他机制 |
| RT-05 | 修改任一有效设定后新检查拒绝；旧故事继续冻结的+3而非新正文中的数值 |

单元与隔离服务提交只能证明确定性机制；受控叙述不是真实供应商质量或人工签收。部署前还需候选备份/升级演练及实际版本核验。

## 仍未完成

AD-3原要求中的既有第三方条件、赋值、一次性奖励及完整交易转换仍需有完整依据的样本；本例只覆盖初值和回合增量。四张用户测试卡的动态定价、库存、周期、掷骰等仍不支持持续运行。不能因新增一个计数器关闭AD-3/5或EXP-ADAPT；这也不是通用agent完成。
