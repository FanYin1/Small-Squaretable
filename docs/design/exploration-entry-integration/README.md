## 复现

在项目根目录运行：

```sh
npm run check:exploration-entry
```

需要依赖已安装、Playwright Chromium 可用、Docker 可用，并已缓存 `pgvector/pgvector:pg15` 与 `redis:7-alpine`。脚本使用 `--pull=never`；端口 55441、55442、55448、55449 必须空闲。它构建当前前后端，创建独立 PostgreSQL/Redis，迁移空库、运行受控模型与真实浏览器检查，结束后删除本次容器和临时秘密文件。3080 的数据库、镜像和服务，及 5188 的原型服务不参与此次写入。

矩阵与业务检查共享正常生产 API 限流，脚本会按响应头等待窗口恢复，通常需要数分钟。失败诊断只保存本次合成页面和 API 路径/状态；完整日志保存在权限受限的临时文件，不应复制进公开文档。受控模型只证明传输、落库与结算链路，不能证明叙事回应质量、状态裁决或长期记忆。

检查范围与剩余工作见 [入口验收记录](../../deployment/exploration-entry-acceptance.md)；任务状态以 [活动待办](../../product/backlog.md) 为准。
