# 07A / 07C 页面核对

打开 [对照页](index.html) 切换发现、详情、可选身份、我的故事、创作和账户；每页覆盖390/768/1440px、明暗主题、原型与正式构建。72张对照截图已从本轮最终通过的入口运行归档，来源为`2cee2683-790c-4bdc-83a2-6712240aeace`；另8张游玩/记忆截图位于交付证据目录。

## 数据与视觉差异

| 页面 | 与原型共同点 | 正式实现的区别及原因 |
| --- | --- | --- |
| 发现 | 顶部四入口、暖纸/暖黑、琥珀操作、封面卡及快速开始 | 保留搜索、分类、收藏与分页；没有虚构的热门数量或固定演示推荐 |
| 详情 | 故事情境、开场预览、开始/继续分开 | 768px正式页仍为横向封面与介绍，原型为通栏封面；原型的身份/同伴、资料双卡在正式页由真实诊断和背景说明承载，未实现逐像素复刻。费用、评分和评论沿用现有服务；此差异需要用户视觉确认 |
| 可选身份 | 可直接开始，可另选身份 | 正式人设来自账户，支持默认、固定称呼约束及失败恢复；不将原型文本框当作完整身份协议 |
| 我的故事 | 继续原档、另开、保存经历摘要 | 摘要/状态以真实数据为准，无摘要时显示缺省说明；生命周期工具沿用07E |
| 创作 | 相同导航、卡片预览、开场片段、色彩层级 | 正式编辑器保留完整字段、绑定、版本及协作工具，页面明显长于原型简化表单；本地预览、服务端保存与发布审核分别说明 |
| 账户 | 阅读偏好、主题/语言、账户入口 | 正式用户资料、权限和账本是实际API数据，点数独立页查看；不复制原型虚构余额/人物身份或本地同步状态 |

原型字体、图像裁切、信息密度及部分卡片比例仍有差异，本文解释原因，不代表用户批准全部差异。创作与账户页并非逐字段同内容截图；入口四页才使用相同两张故事素材。无头像账户的缺省显示和真实上传头像质量需结合用户体验检查。辅助管理页（世界书、账号安全等）继续使用现有DashboardLayout，未计入本次六页外观签收。

## 证据边界

- `reference-*`为已保存原型；`production-*`为真实API下的正式构建，均包含实际截图而非设计示意。
- 图片摘要、原始PNG摘要和来源运行记录已写入`manifest.json`。正式候选部署与实际只读页面证据另见[交付记录](../../deployment/story-entry-creator-07ac-completion.md)。
- 不新增付费验证。模型回应由本地替身提供，不证明真实剧情质量；OPEN-01/02、精确视觉、真实手机与首发内容签收保持开放。
- 复现入口矩阵：`node scripts/exploration-entry-check.mjs`；创作/账户：`node scripts/exploration-entry-check.mjs --creator`。两条使用相同隔离端口，应顺序执行。
