# 自托管字体来源与许可

本目录的 `newsreader.woff2` 复用项目的 `public/fonts/newsreader-latin.woff2`，字节内容一致。字体来源为 Google Fonts 的 Newsreader v26，版权归 Production Type，采用 SIL Open Font License 1.1。

许可与版权声明全文随文件分发，见 [NEWSREADER-OFL.txt](NEWSREADER-OFL.txt)。上游项目：https://github.com/productiontype/Newsreader 。

允许在许可条件下嵌入、再分发与自托管；不得单独售卖字体本身。此原型不包含 Plus Jakarta Sans 或 Newsreader 的其他分片。
