# R2 前端交互样板

这是一份独立设计评审实例，沿用暖黑 / 暖纸、琥珀、情境卡片与阅读优先方向。用户已确认按照计划推进至 R5；实际生产改造的证据与待签收项见 `docs/deployment/frontend-r5-acceptance.md`，不要将此样板当成生产服务或生产验收结果。

## 运行

在仓库根目录运行 `npm run demo:frontend`，打开 `http://localhost:5187`。端口冲突时可设 `FRONTEND_DEMO_PORT`。服务器仅监听回环地址，只提供样板与两份本地字体，不提供业务 API 或任意文件读取。

`npm run demo:frontend:check` 运行 Chromium 检查，要求演示已启动且 Playwright Chromium 已安装。截图写入 `/tmp/squaretable-frontend-redesign/`。

## 评审路线

1. **发现**：查看层级、搜索、筛选、收藏；点击任意故事卡，确认详情与所选内容一致。
2. **身份**：详情 → 新故事 → 输入名字 → 进入；Escape 取消并回到触发按钮。
3. **阅读**：输入行动，查看预写回复，停止后保留部分文字；返回我的故事后继续。
4. **设置**：调整正文字号；模型 / 记忆 / 导出只解释计划位置，不提供伪功能。
5. **状态**：顶部选择空列表、加载失败、生成失败、余额不足；确认提示与草稿表现。
6. **主题与尺寸**：深浅切换；390、768、1440px 检查四入口、详情、阅读与弹窗。
7. **创作与我的**：创作可输入公开介绍并预览，但不会保存或发布；点数为固定示例。

## 验证与限制

2026-10-22 已通过脚本交互检查，覆盖搜索、筛选、收藏、身份与焦点恢复、模拟生成 / 停止 / 失败 / 余额不足、字号、空态与错误态、预览文本转义，以及六页面与身份弹窗 × 三尺寸 × 两主题，共 42 张截图。已抽查代表性的桌面发现 / 阅读、平板详情、手机发现 / 阅读 / 弹窗。

这是浏览器模拟尺寸，不等同真机软键盘、读屏或完整对比度审计。尚未取得用户视觉确认。没有调用真实模型或 API，没有写数据库或账本，状态只在当前页面内存中保留，刷新重置。生产 3080 服务不受影响。

实现计划见 [前端改版修改计划书](../../product/frontend-redesign-plan.md)。只有生产组件接入真实数据、异常回归与用户逐页签收后，才能把相应生产工作包标记完成。
