# 正式前端入口页：首批画面证据

日期：2026-10-22。来源：`e2e/frontend-redesign.spec.ts` 对正式前端构建的浏览器截图，API 使用合成 fixture。对应 EXP-07A，不是新状态/记忆系统或真实供应商验收。

本目录保留发现、详情、可选身份、我的故事四页的 390 / 1440px 明暗截图（WebP）；原始 PNG 及 768px 等回归截图在 `/tmp/squaretable-exploration-entry/`。`manifest.json` 记录归档图片和本批主要源码的 SHA-256，避免把后续修改误认为截图对应的实现。

参考原型保持在 [原始开发快照](../exploration-baseline/README.md)，不能覆盖它。具体映射、设计差异、检查结果和未完成项见 [首批验收记录](../../deployment/exploration-entry-acceptance.md)。原型与本批 fixture 题材不同，布局与令牌可对照，但同内容逐页对照及用户签收尚未完成。
