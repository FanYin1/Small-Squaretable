## 运行

在项目根目录执行：

```bash
node scripts/exploration-demo-server.mjs
```

访问 `http://localhost:5188`。服务只监听 `127.0.0.1`；远程 IDE 环境将 5188 端口转发至本机后访问。可用 `EXPLORATION_DEMO_PORT` 指定其他端口。此示例与 3080 本机候选、5187 旧改版示例分开。

不需要登录、邀请码、模型密钥或数据库。服务器只提供本示例的 HTML/CSS/JS 与两份项目字体；不开放项目目录或 API。

## 七类页面与直达入口

用户随后要求“给出各个页面的实例效果”，本轮扩展为七类页面。四个主要导航是“我的故事 / 发现 / 创作 / 我的”，游玩时收起平台导航，保留返回入口。以下路径接在 `http://localhost:5188/` 后即可访问；路径支持刷新、浏览器前进与后退。

| 页面 | 路径 | 主要视觉与可操作行为 |
|---|---|---|
| 发现 | `#discover` | 大标题、双故事封面与情境介绍；直接开始或查看详情 |
| 角色卡详情 | `#detail/orbit`、`#detail/book` | 封面与体验介绍分栏，说明身份、人物、参与方式与随卡设定；可预览开场 |
| 开局身份 | `#setup/orbit`、`#setup/book` | 可选称呼、固定示例身份与设定提示；不强制经过此页，不要求额外选世界 |
| 探索游玩 | `#play/orbit`、`#play/book` | 正文、推荐行动、自由表达与按卡资料窗口；沿用已有预写分支 |
| 我的故事 | `#stories` | 实际开始过的示例、原文摘录、地点与草稿提示；无进度时显示空态 |
| 创作 | `#create` | 基础信息、开场与身份、绑定资料说明；实时文本预览与本地草稿保存 |
| 我的 | `#account` | 本地体验身份、实际开始数量、主题字号与保存位置；不展示虚构余额 |

推荐先走“发现 → 详情 → 可选称呼 → 游玩 → 我的故事 → 继续”，再查看创作与账户。称呼仅在新开局时设置；已开始的示例只读展示原称呼，避免改写历史。每张示例卡仍只有一份进度；多存档创建、删除、重命名尚未实现。

创作页保存的是独立的浏览器草稿，不会发布到市场，也不会替换两张示例卡。资料绑定目前只展示边界说明，没有文件导入或依赖解析。账户页仅展示本地体验与可工作的阅读偏好，不模拟真实登录、余额或订阅。

## 建议体验路线

### 雾海之外：线索、资源与地图

1. 首页选择“雾海之外”，直接进入船长视角，不要求另选世界。
2. 点击“核对两张记录的时间”：正文出现结果，资料窗口新增一条有出处的线索。
3. 切到“地图”，点击调度室：只查看地点，不移动、不生成。
4. 点击地图中的“前往调度室”：地点与剧情时间随这一轮完成更新。
5. 向调度员询问来源，再返回维修舱；此前确认的线索仍在，剧情时间持续向前。
6. 在资料中点击“查看这段经历”，定位到相应原文。

支持的自由输入示例：“核对记录的时间”“问问林澈”“前往调度室”“询问记录来源”“返回维修舱”。输入仅匹配预写分支，不能理解任意复杂意图；未覆盖的输入会保留并说明限制。剧情信用点为固定的虚构资源，这个片段没有消费行为，不代表平台点数。

### 晚一点开门：表达偏好与延续约定

1. 返回首页，选择“晚一点开门”，以书店店主身份开始。
2. 自由输入“我想晚一点开门”：营业时间改为 10:00，许宁回应你的偏好。
3. 选择“约好下次一起挑选新书”，记录 10:30 的约定。
4. 选择“继续到约定的那个上午”：她按上次约好的时间到来。
5. 查看“人物”“约定”；此卡没有地图、金钱或好感度数值面板。

也可以先约定再修改营业时间：原约定保留，新记录注明改为 10:30，分别指向发生当轮。不会改写过去的正文。支持“问问许宁”“约好下次见面”“继续到约定的上午”等输入。

### 恢复与异常

- 切换故事或刷新：两种卡各自保留进度与草稿，首页出现“继续这段经历”。
- 续写过程中点击“停止”：保留已收到的片段及草稿，不提交这一轮的地点、线索或约定变化。
- 在“设置”中启用“让下一次行动模拟失败”：下一次行动失败后保留草稿，显式重试成功才更新状态。
- 设置中可调整字号，顶部可切换明暗主题；手机点击“查看状态”打开资料抽屉，关闭后返回触发按钮。
- “重置当前样例”有二次确认，只清除此卡在当前浏览器的示例进度。

所有正文、分支、地图和数值均为原创演示数据。未解析真实角色卡或世界书，未接模型、收费、账号或生产存档。这里的续写是定时展示预写文本；事实变化由固定规则在整轮结束后一起提交。不能据此认定长期记忆、通用状态提取或世界书兼容已实现。

使用浏览器 `localStorage`，键为 `small-squaretable-exploration-demo-v1`。保存提示仅指当前浏览器成功写入，不是云存档保证。清理站点数据会丢失进度；不同浏览器/端口不共享；不支持多个标签页并发编辑同一存档。

推荐选项暂用“点击立即提交”供评审；OPEN-02 保持开放。错误纠正、回退和分支规则仍属 OPEN-01，未用普通重生成按钮代替。当前只包含有限的开局称呼、两卡进度列表和本地创作草稿，不代表完整卡库、创作后台、通用身份或多存档管理已实现。

本轮颜色、字号、字体搭配与抽屉尺寸是视觉试样。若获确认，需映射回正式前端的设计令牌与组件，并与生产页面逐页对照，不能把独立示例上线当作生产改版完成。
