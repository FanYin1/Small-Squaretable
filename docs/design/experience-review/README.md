# 页面与行动纠正评审实例

2026-10-25。本包用于收敛EXP-02的页面差异和EXP-06的交互语义，规则见[评审提案](../../product/experience-review-proposal.md)。它是可操作的评审材料，不是生产纠正功能，也不代表用户签收；EXP-02、EXP-06、EXP-07D继续开放。

## 打开与评审

在仓库根目录运行：

```sh
node scripts/exploration-review-server.mjs
```

浏览器打开 `http://localhost:5189`。服务只监听本机127.0.0.1；远程IDE需转发5189端口。默认端口已占用时先检查已有实例，或使用`EXPERIENCE_REVIEW_PORT`指定其他端口。

1. **页面对照**：选择七个页面、390/768/1440宽度及明暗主题，查看现有原型与生产截图，逐项记录保留或调整意见。发现、详情、身份、故事库使用相同素材；创作与账户的数据差异单独说明。游玩页仅有现有生产截图，明确缺少同场景原型，不伪造对照。
2. **行动与纠正**：在港口和书店两个预写场景中，比较推荐先入草稿与点击直接提交。切换试用不等于确认默认方式；只有主动点击“记为我的倾向”才记录意见。已有草稿替换需确认，直接提交推荐保留自由输入。
3. 依次预览阅读标注、换一种说法、事实纠正和改变过去选择，查看各自对原文、状态与记忆的拟议影响。事实纠正缺少依据时不能预览；原样例保持不变。自由输入只演示行动提交，不生成后续剧情。
4. **反馈草稿**：检查各页面和交互意见，导出JSON留作讨论依据。导出固定标为`unconfirmed_draft`，不生成验收通过记录。

桌面状态区展开，窄屏默认折叠以优先呈现正文。对话框支持Escape与焦点返回；输入法组合期间Enter不提交。意见仅保存在当前浏览器的`localStorage`（键为`squaretable-experience-review-v1`）；损坏数据不覆盖，写入失败会提示，当前内存草稿仍可导出。浏览器清理数据或更换设备不会自动同步。

## 证据与边界

- 对照使用[07AC原始清单](../exploration-07ac-integration/manifest.json)中的72张既有图片，以及6张既有生产游玩截图；它们不是本轮重新部署的截图。
- 本轮评审页的12张截图及摘要在[截图清单](evidence/manifest.json)，14组检查记录在[验证报告](../../deployment/evidence/experience-review.json)。覆盖图片来源、页面切换、草稿保护、输入法事件、纠正预览、反馈持久化/失败、窄屏布局与静态服务隔离。
- 自动化视口和合成输入法事件不等于真实手机或人工体验验收；COR-01至COR-08是后续生产验收要求，本轮没有执行。
- 仅提供白名单静态资源，CSP禁止连接；无登录、业务API、数据库写入或付费模型调用。3081仍为07AC候选，3080及5188保持原状。
- 分支创建、表达修订、事实重算与记忆重建尚待产品语义确认和生产实现；不能用预写结果替代这些能力。

复现检查（服务需先启动）：

```sh
node scripts/exploration-review-check.mjs
node scripts/check-exploration-baseline.mjs --compare-current
```

下一步将用户对具体页面、推荐提交和纠正规则的反馈补入决策记录，随后实施确认范围并执行生产验收。没有确认来源时，不将新增建议升级为DEC，也不关闭OPEN-01/02/03。
