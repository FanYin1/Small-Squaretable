本目录下 55 份文件均为 2026-02-05 至 2026-03-01 期间各轮迭代的计划文档。它们记录了当时的想法与执行过程，作为"为什么代码长这样"的背景材料有价值。

**但其中多数文档的方向与当前定位冲突。** 举例：`2026-02-22-social-feature-enhancement.md`、`2026-02-22-voice-audio-multimodal.md`、`2026-02-23-realtime-collaboration.md`、`2026-02-24-template-marketplace.md` 规划的方向，在当前定位下属于「明确不做的事」。

读这些文档时请注意：

- 文件名日期是**撰写日期**，不是完成日期。文档里的"✅ 完成"只说明当时那一轮的执行状态
- 这些计划彼此之间有重叠与矛盾（例如 `2026-02-23-character-management.md` 与 `2026-02-24-character-management.md`），它们是串行累积的，不是一套协调的规划
- 不要从本目录派生新任务。新任务一律进 [`../product/backlog.md`](../product/backlog.md)

**如果某份历史计划里的某个想法仍然值得做**，把它写进 `backlog.md` 并补上验收标准，而不是复活原文档。
