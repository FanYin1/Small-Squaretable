# 推荐行动的场景引导语

2026-11-02。对应 DEC-05、INV-02/06。用户同意在推荐按钮前增加一段自然引导；本次完成源码与隔离验证，未部署远程，不关闭探索体验父工作包。

## 可见效果

故事正文下方依次展示简短引导语和原有三个竖排推荐按钮。例如使用合成场景：

> 门锁上的划痕和来客的反应都值得留意。你可以从下面的方向继续，也可以直接输入自己的想法。

下方按钮分别为“检查门锁上的划痕”“询问来客为何停下”“先留意来客的反应”。引导语采用 13px 次级文字，不增加标题或卡片容器；点击仍只发送所选行动，自由输入保留。

旧消息、开局或没有有效引导语时显示“你可以从下面的方向继续，也可以直接输入自己的想法。”，不从旧正文随意摘句伪装成场景建议。中断轮仍不显示推荐；只有原卡规则行动而没有推荐时不新增引导段。

## 生成和保存

- 正常与已确认行动的现有模型请求均增加可选 `recommendationLead: { text, evidence }`，与正文、三个推荐一起生成，不增加独立模型调用；会增加少量提示词和输出 token。
- `text` 为最多 120 字符的单段纯文本，提示要求关联已显示情景、不重复三个按钮、不新增事实或许诺结果，并留下自由输入空间。服务端拒绝空白、超长、尖括号及段内控制字符；前端对存量字段再次校验并以文本渲染。
- `evidence` 必须是当前可见回复中逐字出现的 2–300 字符。无效的可选引导语被丢弃，不使有效行动理解或正文失败。
- 通过校验的文案保存到消息 `extra.storyRecommendationsLead`；WebSocket 完成事件、前端消息和分支复制均保留。缺失或无效时使用通用文案。无需数据库迁移。

## 验收边界

证据逐字存在只能验证引用来源，不能证明整段引导语与原文语义完全一致。真实供应商是否稳定生成贴切文案、真实账户生成后刷新和分支持久化、整页视觉与手机真机签收仍未验证。本轮不调用付费模型、不改变工程预算，不更新远程服务。

本次实现引导段落与兼容链路；推荐的跨轮去重、版本绑定及进一步质量评估不在本次新增范围内，未宣称这些能力已完成。
