# 多会话 CSRF 隔离修复

日期：2026-10-24。对应EXP-07C-CSRF；本项完成源码修复、隔离环境验收及原绑定流程回归，不代表3081候选已升级或完整探索体验验收完成。

## 问题与修复

此前`extractSessionId`截取Bearer访问令牌的前32字符作为CSRF存储键。不同账户JWT共享头部及载荷前缀，可能写到同一键；获取令牌接口每次又覆盖旧值，造成另一账户或标签页已有令牌失效。仅更换键仍不能解决同一访问令牌下多页面相互覆盖，因此同时修复两处。

- 服务端以完整访问令牌的SHA-256摘要作为会话标识，使用`csrf:v2:`命名空间，不将原始访问令牌写入Redis键。
- Redis在一次原子操作中读取或创建CSRF令牌，已有有效令牌保持不变；内存实现具有相同行为。有效期仍为一小时，重复读取不延长有效期，过期或显式撤销后重新签发。
- 访问令牌增加随机`jti`，同账户同秒多次登录也得到不同凭证。已有访问令牌验证不要求新增字段。
- 正式获取CSRF接口增加认证检查，仅向有效且启用的账户发放；响应禁止缓存。非法、多字节CSRF值被拒绝，不因字节长度差异触发500。
- 前端缓存按当前访问令牌区分；账户切换、访问令牌刷新或登出后，不继续沿用旧缓存。旧异步结果不能覆盖新账户缓存，等待CSRF期间身份改变的写操作明确中止。
- JSON、上传及Blob写请求使用与Authorization一致的访问令牌获取CSRF；获取失败不继续发送缺失保护的写请求。身份过期时保留既有刷新机制，修正了读取`/auth/refresh`响应的格式错误：服务实际返回`data.accessToken/refreshToken`，此前误读为`data.tokens`。

不自动重放失败的业务写入。刷新认证或CSRF后，由调用方明确重试，避免重复提交剧情行动、绑定或消费。

## 验收

7个相关测试文件共89项通过，其中新增12项覆盖共享前缀隔离、并发复用、选择性撤销、过期、不合法字符、同秒签发、前端缓存与迟到响应、刷新后首次写入及失败不发送业务请求。对同秒签发用例固定时钟后，另复测7项JWT用例通过。类型检查与前后端构建通过；定向lint零错误、4条既有警告。

实际一次性PostgreSQL/Redis及正式后端通过5组专项检查，见 [会话隔离证据](evidence/csrf-session-isolation.json)：

1. 获取接口拒绝未认证/无效凭证；两份具有相同前32字符的真实访问令牌各用独立CSRF；六次并发获取得到稳定结果。
2. 缓存的CSRF在其他账户登录后仍有效，跨会话混用被拒绝；同账户另一次登录也拥有不同访问凭证和CSRF。
3. 两个账户、三个独立Chromium上下文，在真实角色编辑页并发绑定资料，无接口拦截或模拟仓储。
4. 两个页面刷新后，与另一持有新访问令牌的页面并发解绑；六次界面写入全部200，页面错误为零。新访问令牌下的第一次写入自动获取匹配的CSRF。
5. 实际Redis令牌过期后拒绝旧值且未创建角色，重新获取后成功，另一个会话仍有效。

浏览器中访问令牌刷新使用真实`/auth/refresh`接口，再把返回凭证设置到仍打开的页面，验证其已有CSRF缓存失效。自动处理过期访问令牌的分支单独以单元测试覆盖，不能冒称浏览器经历了六小时过期。Redis过期使用短TTL注入，不是等待一小时的耐久试验。

移除原世界书验收脚本「每次写入前刷新CSRF」的临时绕行后，原5组绑定/权限/并发/存档冻结/受控生成检查再次通过，见 [无绕行回归证据](evidence/worldbook-bindings-csrf-regression.json)。此前报告保留，不改写当时的问题。

初次专项浏览器检查因集中刷新页面触发既有API限流而失败。最终脚本按响应中的剩余次数和重置时间等待，未放宽生产限流。运行器结束后清理临时容器。

## 复现与发布边界

```bash
node scripts/exploration-entry-check.mjs --csrf
node scripts/exploration-entry-check.mjs --bindings
```

两个入口分别运行，使用相同保留的隔离端口，不能同时启动。证据分别保存在`/tmp/squaretable-csrf-session-evidence/`和`/tmp/squaretable-worldbook-bindings-evidence/`。

本轮没有新增迁移、修改线上配置或更新3080/3081/5188。后续部署须同步更新前后端；旧CSRF存储不复用，已打开的旧页面需重新获取令牌，必要时刷新页面再明确重试。旧命名空间记录自然过期，无需清空Redis。

本项不扩大既有CSRF受保护/豁免路由集合，不改变登录/登出的访问令牌撤销策略，也不改变服务端按用户保存刷新令牌的既有策略。因此不能据此宣称所有设备独立刷新/撤销的完整会话生命周期已经实现。

本轮无真实模型调用；包含受控供应商的既有回归不计作真实供应商质量。累计预算保持398,002/450,000 tokens。EXP-07C-CSRF按本页范围完成；父项EXP-07C、EXP-03B代表卡兼容与EXP-07D整体验收保持开放。
