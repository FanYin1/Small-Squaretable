# 新注册账户与平台无限额度

2026-10-30 用户明确要求“目前给新注册的账户无限额度，平台同时也设为无限”。公网于香港时间 22:04:16 更新，入口为 `http://47.116.114.103/`。

## 实际行为

- `NEW_ACCOUNT_UNLIMITED_CREDITS=true`：生效后邮箱注册、首次第三方登录创建的独立账户自动获得免扣点权限。沿用[账户无限点数机制](../product/credit-exemption-delivery-20261028.md)，余额界面支持显示“无限”，不伪造大额充值。已有账户权限、余额和账本保持原样。
- 授权、授权审计与创建账户在同一注册事务内。任一步失败，账户、邀请码消费和授权一起回滚；共享租户或账户归属不符时拒绝授权。
- `PLATFORM_DAILY_TOKEN_LIMIT=-1`：明确取消全平台每日 token 上限，仍累计实际用量；不再因每日额度触发 `PLATFORM_SPEND_LIMIT`。正整数上限仍可配置，生产环境仍拒绝缺失配置。
- 公网保留 `BILLING_MODE=credits`。免扣点生成仍记录预扣生命周期和实际用量，结算扣点为零。工程模型测试预算、既有未知回执暂停状态独立保留；本次付费模型调用为零。

## 恢复限制

将 `NEW_ACCOUNT_UNLIMITED_CREDITS=false` 后重建应用容器，可停止后续新注册授权；已获得的授权需按账户使用 `scripts/credit-exemption.mjs revoke <user-id>` 撤销。平台恢复正整数上限时会继续使用当天累计计数，不清零。完整部署回滚可恢复上述目录中的 `env.before`、`compose.before.yml` 与 `image.before` 所记镜像，只重建应用容器。
