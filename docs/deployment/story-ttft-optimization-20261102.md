# 故事首字延迟优化：源码与远程交付

日期：2026-11-02。关联 DEC-31、DEC-30、DEC-05、INV-02/04/05/06/08，属于既有性能优化方案的单人生成切片。用户对首字延迟优化方案回复“可以”后实施。初次源码交付未部署；随后按用户“部署远程同时用流式传输”发布，见末节。未调用真实模型，也未改变工程测试预算暂停状态。

## 实际行为

此前直接回复需等完整模型输出、结构校验和保存后才显示正文。本次默认流式单人直接回复在模型输出正文时即发送预览，页面标记“生成中 · 尚未确认”；预览只在当前页面内存，不提前写入消息列表、故事事件、推荐或记忆。

隐藏的 `<story-intent>` 控制块及跨网络块拆开的标记不显示。服务器保留原始完整输出用于校验、事务与计费；停止或达到输出上限仍按已有中断路径处理。

最终 `ASSISTANT_MESSAGE_DONE.content` 携带数据库已保存的权威正文。客户端用它替换预览，而非追加：包括正常正文、正则处理后的正文、空串及校验失败提示。对应推荐、引导语和可用分支在最终消息中呈现；中断消息不能作为可用分支起点。旧无 `content` 的 DONE 仍可消费。

状态冲突、生成错误或结束时漏收 DONE，均清理预览并按已有消息恢复链路读取数据库。导航或重连后只恢复已保存结果，不续接离开前的实时预览；迟到的已退休请求不会重新打开预览。此行为没有恢复旧版的行动审批表。

## 生成前的等待

- 记忆仓储以相同用户、角色及故事范围执行关联向量表的 `EXISTS`。没有可检索向量时不调用 embedding、不执行 hybridSearch，也不更新访问时间。不缓存空判断；新记忆或补入向量后下一次检索立即重新判断。有记忆时会增加一次数据库查询，这项取舍尚无真实数据库耗时基准。
- 独立故事 `contentSnapshotVersion === 1` 的通用情绪分析移至回复保存并发送 DONE 后，先处理输入再处理回复。该通用情绪不参与此类故事当前提示词；无效或中断直接回复不衍生情绪及成长。仍是同轮处理中的后置步骤，不是新增后台队列，可能继续影响结束通知与下一轮解锁时间。
- 非流式文本模板仍需等模型完整返回，不能因此获得逐字提前显示。

## 计时口径

全部使用单调时钟 `performance.now()`。不把服务端时间与浏览器时间直接相减。

| 位置 / 字段 | 起止点与限制 |
| --- | --- |
| 服务端 `historyReadMs` | 当前单人 handler 的历史读取 |
| 服务端 `promptBuildMs` | 组装增强提示词；旧式会话仍包含前置情绪步骤 |
| 服务端 `contextBuildMs` | 上下文选择及必要摘要读取 |
| 服务端 `preparationMs` | 进入单人 handler 至预扣/模型生成分支开始；不含更早鉴权或 prepareStoryTurn |
| 服务端 `firstTokenMs` | 调用流式 LLM service 至收到首个非空文本 delta；包含该封装内部准备和网络，不是供应商纯推理耗时，也不是推理模型的首个隐藏思考 token |
| 服务端 `firstVisibleMs` | 进入单人 handler 至首次广播非空可展示 chunk；是广播时间，不是浏览器呈现时间 |
| 服务端 `modelTotalMs` / `generationTotalMs` | 分别从生成分支/单人 handler 开始计至模型输出完整返回；不含后续提交和派生处理，生成抛错时没有该条完整性能日志 |
| 浏览器 `sendToFirstBodyChunkMs` | 接受发送操作至当前请求首个非空白正文 chunk；界面入口包含必要开场保存准备 |
| 浏览器 `firstBodyChunkToPresentationApproxMs` | 首 chunk 至 Markdown 正文 DOM 更新并再跨一帧 |
| 浏览器 `sendToPresentationApproxMs` | 接受发送操作至上述呈现近似 |

浏览器写入 `[Chat] reply_performance` 控制台日志，只有固定标签、数值计时及本页 attempt/selection 编号，不含正文、提示词、用户或请求标识，也不新增网络遥测。每次发送重新计时，空白块、其他故事/请求、旧回调、隐藏页面及导航/失败/重连不形成有效呈现样本。格式/控制块造成正文尚无文本时，等待后续 DOM 更新。

呈现近似不是硬件 paint 时间，也不证明用户当前滚动位置能看到这段文字。非流式 DONE 没有首 chunk 样本；不能把缺失值填零。失败前已经输出的控制台样本仍可能存在，不能直接混入成功请求的性能统计。
