# 前端改版 R5：本机验收候选

日期：2026-10-22（香港时间）。依据：`docs/product/frontend-redesign-plan.md` 与用户“按照计划书，持续修改到 r5 阶段”的确认。

本记录区分**开发实现、本机验证、用户签收**。R5 候选不等于视觉签收、公网发布或真实供应商额度验收。独立演示仍仅供对照，不替代生产服务。

## 1. 交付范围

| 阶段 | 生产实现 | 保留的业务边界 |
|---|---|---|
| R1 整体布局 | 共享品牌与四主导航；桌面 240px；1024px 以下抽屉；非阅读页四项底栏；阅读中无底栏 | 原 URL、授权和模块开关保留；审核员进入内容管理，管理员进入用户管理 |
| R2 故事进入 | 发现标题、三列卡片、移动横向卡片、紧凑筛选；真实故事列表、空态与重试；详情双列；已验证的最近故事可继续 | 不展示虚构推荐、关系或费用；详情只沿用现有接口返回字段；继续与新建分开 |
| R3 阅读与费用 | 收起模型、参数、记忆、导出、管理操作；15/17/19px 字号；弱气泡居中正文；移动输入重排；余额和返回故事链接 | 沿用生成请求、停止、恢复、草稿与账本机制；点数模式不展示订阅套餐；未知余额不显示零 |
| R4 配套体验 | 创作/账户/登录/注册统一外壳；作者预览复用生产卡片及 Markdown 阅读组件；三步可跳过引导；登录返回路径校验 | 不新增故事 schema，不改变导入/审核流程；不把私密人格设定当公开卡片文案；引导按账号记录 |
| R5 验证交付 | 生产构建浏览器矩阵、单元回归、隔离真实 API 检查、镜像版本与回退记录 | 真机、读屏与用户逐页签收保持未完成，不能以截图或测试替代 |

补充防回归：切换账号会清理故事列表、选中故事、模型缓存及相关展示；旧列表/余额/账本响应不能覆盖新账号。只读进入说明展示服务端模型配置与余额，不调用生成接口。

本轮发现并修正的偏差：`/chat` 不再偷偷自动进入旧会话；移动发现搜索/筛选过高已收敛；768px 创作溢出已修复；编辑预览不再独立复制旧卡片；点数模式不再同时出现订阅价目；审核员入口不再指向仅管理员可用的用户管理；认证主按钮不再使用低对比度白字压琥珀底。

## 2. 与演示的逐页对照

| 页面 | 已落地的设计结构 | 有意保留的差异 / 验收关注点 |
|---|---|---|
| 发现 | 左侧四主导航、大标题与说明、独立搜索、继续条、三卡并排；手机横向卡片 | 没有正式封面时显示首字与中性底色，不拿演示插画冒充真实故事；题材仍用现有分类，标签/排序折叠 |
| 我的故事 | 真实会话标题、服务端摘要、最后活动时间、继续入口；新故事引导去发现 | 服务端摘要为空时明确暂无消息，不调用模型编造摘要；多人和模板保留在更多工具内 |
| 详情 / 身份 | 封面介绍双列、开场、参与和费用说明；已有故事继续与新故事分离；身份确认弹层 | 详情开场仍是安全纯文本；实际阅读使用富文本渲染。缺乏结构化关系、钩子字段时不补造 |
| 阅读 / 设置 | 默认仅故事与身份、正文、输入/点数；设置显式展开才显示工具；窄屏隐藏底栏 | 保留多角色、参数、调试、导出等真实能力，设置比演示更丰富；不伪造章节或记忆状态 |
| 创作 / 编辑 | 同一外壳、创作说明与次级入口、生产故事卡片、可见管理操作；预览同源 | 首批保留兼容旧角色卡的编辑字段，未做新的故事内容 schema；预览不会提交或生成 |
| 我的 / 费用 | 同一品牌和导航、身份/安全/账户入口、真实点数规则与流水、可返回阅读 | 在线支付未接入，不出现虚构充值成功；订阅模式仍保留现有订阅管理 |
| 认证 | 共用品牌、叙事介绍、暖纸/暖黑表单、桌面双列与手机单列 | 仍保留邀请码、年龄确认、MFA、OAuth 原能力；SMTP 未配置不表示邮件功能通过 |

现有主题令牌继续使用，不把演示 CSS 全局覆盖到 Element Plus。对照时应看信息层级、布局、控件和真实状态，不要求无封面与有演示插画两者逐像素相同。

## 5. 用户签收清单（尚未签收）

1. 在 3080 强制刷新，核对四主导航、发现首屏、故事详情，确认这不是 5187 独立样板。
2. 用自己的身份进入，取消不创建故事；继续不覆盖已有故事；刷新与返回仍是同一故事。
3. 检查正文、字号、输入、阅读设置；确认旧管理能力可找到但不再占据默认页头。
4. 检查创作编辑预览、发布/导入入口、账户与费用页，分别看深浅主题。
5. 真机检查软键盘弹起/收起、横屏、长输入、200% 缩放、读屏焦点与多角色长正文；桌面 Chromium 截图不能代替这些检查。
