# 多渠道模型接入

2026-10-31。对应 INV-05（取消与用量边界）、INV-08（验收证据与能力声明）。本包提供可配置的文本模型协议接入；供应商逐模型的真实剧情质量验收仍开放。

## 已实现的行为

- 管理员在 `/admin/models` 新增、选择和编辑独立渠道；每个渠道维护自己的端点、密钥、模型列表、默认模型与容量。新增渠道不会覆盖原渠道或继承其密钥。
- 支持 OpenAI Chat Completions 兼容协议、Gemini 原生协议、Anthropic Messages 原生协议。普通和流式聊天统一返回项目使用的文本、完成原因和用量格式；Anthropic 思考块不进入正文，错误、工具结束及中断流不会被标为正常完成。取消可传递到上游。
- 提供 OpenAI、Claude、Gemini、DeepSeek、通义千问、Kimi、智谱、豆包、Grok、OpenRouter、硅基流动及 Ollama 的可编辑端点模板。模板不预填模型 ID 或虚构容量，也不代表已逐家发起真实调用。
- 模型名全站唯一；支持将站内别名映射到上游模型 ID 或部署 ID。同名模型可以通过不同别名分配到不同渠道。
- 可选择 `max_tokens` / `max_completion_tokens`，关闭采样、惩罚、流末尾用量请求或 JSON 模式。原生适配器自行转换输出字段；原生 Claude 的 JSON 请求采用提示约束。
- 保存先原子替换加密配置文件，再发布内存配置；写入失败保留旧配置。后台接口只返回密钥是否存在，不回显密钥；编辑时留空只保留当前渠道密钥。
- 可设平台默认渠道；新建会话的默认模型、记忆整理沿用平台默认模型逻辑。既有会话已选模型不会随默认渠道切换而批量改写。

## 配置步骤

1. 管理员登录，进入“模型管理”，点击“新增渠道”，选择供应商端点模板。
2. 核对接口协议、地区端点与 API 密钥，填写账号实际可用的模型 ID。豆包等服务可以使用部署 ID；服务端必须能访问所填地址。
3. 填写默认模型与容量 JSON。模型列表、默认模型、容量及别名的键都使用站内模型名。下面仅演示格式，数值需按实际模型文档修改：

   ```json
   {
     "story-model": {
       "contextWindow": 128000,
       "maxOutputTokens": 8192,
       "requestOutputTokens": 4096
     }
   }
   ```

   `contextWindow` 为上下文容量；`maxOutputTokens` 为输出能力；`requestOutputTokens` 为本项目的请求输出上限。必须为正整数，请求上限不得超过输出能力，且为输入保留空间。容量留空时，未知模型仍使用保守的 4096 上下文 / 2048 输出默认值，大角色卡可能被容量保护拒绝。

4. 需要同名模型多渠道接入时，模型列表使用 `story-model` 等唯一名称，再填写别名映射，例如 `{"story-model":"actual-upstream-model-id"}`。前端模型选择与会话保存仍使用站内名称。
5. 推理模型或严格网关若拒绝采样/惩罚字段，在“请求兼容选项”关闭相应选项；要求 `max_completion_tokens` 的 OpenAI 兼容端点选择对应字段。网关不支持流式用量或 JSON 模式时，可分别关闭。
6. 保存后即时生效；聊天输入栏从现有模型列表选择模型。是否通过剧情结构、推荐与记忆规则，还需独立真实多轮验收。

Ollama 模板中的 `host.docker.internal` 在 Linux Docker 上可能需要额外主机映射，或改为容器可访问的地址。端点模板用于起步，地区、代理前缀和账号权限均以实际服务为准。

## 验证与边界

- 13 个定向测试文件、115 项通过：渠道隔离与加密持久化、旧配置恢复、别名、参数适配、三协议服务路由、缓存计量、流式终止/取消、记忆整理与后台组件等。
- Chromium 在 1440 / 390 两种宽度通过新增 Claude 渠道、提交配置、保留原渠道、页面无横向溢出及无页面错误检查。使用隔离 API 响应与假密钥，不修改生产配置，不代表真实供应商认证成功。
- 先前浏览器脚本缺少 CSRF 响应导致未能发出保存请求；补全隔离接口后同构建两尺寸完整重跑通过。原失败不算成功证据。
- 本轮未发起付费模型调用。既有工程预算的未知用量仍待核实，未绕过暂停限制。
- 本包范围为文本对话。图片、音频、工具调用、OpenAI Responses API 及其他专有协议尚未接入；供应商同属兼容协议也可能有额外参数要求。协议接通不等于所有模型都能稳定执行剧情结构、推荐和记忆契约。
