# 公网页面加载优化（2026-10-30）

用户反馈打开页面普遍缓慢。本轮修复发现页及角色详情首屏的数据负载，已部署到 `http://47.116.114.103/`。对应 EXP-02 页面体验及 EXP-07D 公网访问问题；原 DEC/INV、绑定角色卡、原卡机制及父包验收范围不变。本轮没有付费模型调用。

## 原因与实现

路由已有按需加载，并非打开网站就下载所有页面。主要问题是发现页四张卡的原始 Base64 封面随列表 JSON 一并返回，蔚蓝星域详情页又提前返回完整角色卡及原图。前端即使只显示几段内容，也必须等待大响应下载、解析。

- 搜索和市场列表改用小封面、限长介绍；搜索 SQL 只读取列表所需长度的介绍。内嵌封面生成不超过 32KiB 的 WebP，480px 压缩超限后再缩到 240px；原图不改。转换串行执行、限制输入大小/像素并设置有界缓存，损坏图片不阻断列表。
- 列表缓存使用 `summary-v2` 键，避免命中旧大响应；仅公开搜索共享缓存，`my/all` 绕过共享缓存。保留权限、租户、审核与 NSFW 过滤。
- 新增 `?view=summary` 和 `?view=detail` 只读视图；详情页使用小封面和展示预览，不返回完整 `cardData`。预览仍从原卡判断叙事开场和脚本能力，保留原有兼容警告与展示来源。展示字段限长，宏替换后预览截断位置可能略有变化；原卡和实际开局不变。
- 编辑、导出等需要原卡的操作继续使用完整接口。外链图片地址原样保留，服务端不抓取外部图片。
