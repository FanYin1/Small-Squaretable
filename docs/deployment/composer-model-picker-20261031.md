## 可见行为

- 桌面保持宽工作区，文字、模型按钮及发送控件在同一输入框内；输入随内容增高，最多显示五行。手机使用文字一行、控件一行的紧凑布局，触控按钮至少44px。
- 模型浮层显示后端实际返回的模型名称、上下文容量、当前勾选。超过五个模型时可展开全部并搜索；没有已配置渠道时不添加虚构模型或自动路由。
- 点击当前模型不发保存请求；其他选择等待服务器确认后更新。保存期间暂时禁用发送和重复切换；失败时显示错误、保留原模型与草稿。切换只影响后续轮次，历史回复保留。
- 支持方向键、Home/End、Esc及点击外部关闭，Esc恢复触发按钮焦点。浮层适配手机宽度、长模型名和明暗主题；保留中文输入法、Enter发送、Shift+Enter换行、停止生成及已有语音功能。
- 修复异步保存竞态：切换模型后马上进入另一故事，保存结果更新发起请求的故事，不误改后来打开的故事。
