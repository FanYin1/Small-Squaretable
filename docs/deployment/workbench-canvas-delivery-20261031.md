# 会话主画布与覆盖式工具

日期：2026-10-31。归属 EXP-02，回应用户要求参考上传的 Venice 页面与模型厂商页面，扩大正式会话工作空间。纠正、分支与推荐继续遵循 DEC-20/21/22/28 及既有推荐契约。

## 参考与实现

主要依据用户上传的四张 Venice 页面：稳定单侧导航、轻量会话栏、连续正文、底部输入，以及简洁的角色库和详情层级。公开浏览 Venice/Gemini 超时、Claude 地区受限、DeepSeek 仅展示登录页，因此不把它们记为已查看完整登录后会话的参考证据。保留已选 A 书页风格。

- 会话页移除外壳面包屑顶栏，仅保留一层 64px 会话栏；手机 60px。导航折叠入口移入会话栏，手动收起状态跨页面保留。
- 正文、推荐与输入共用最大 1440px 画布及相同左右边距。手机使用完整视口宽度；修复旧移动网格将 390px 视口压成 228px 主区的问题。
- 分支存档由常驻栏改为覆盖式抽屉，替代前轮“默认窄轨道、记住展开”的实现。资料、阅读设置及记忆均按需覆盖，带暗幕、正文 inert、焦点约束、Escape 关闭与焦点恢复。
- 字号 15/17/19px 直接控制正文；余额、模型、导出、工具及兼容范围进入设置。正文仅在余额不足或读取失败时展示额度提示，兼容诊断默认折叠。
- 推荐仍在正文末尾，点击仍作为自由输入发送；纠正与删除通过管理菜单可达，逐消息纠正保留。本轮仅只读复核已有推荐，没有发送真实生成请求。

## 验证与发现

- 定向组件测试五个文件 88/88 通过，覆盖分支、通用抽屉、ChatWindow、资料抽屉及故事页面；类型检查、客户端生产构建及补丁检查通过。
- 浏览器检查使用真实账号及已保存故事，只读打开会话、私人库、详情，检查三项推荐、明暗主题、字号、抽屉焦点、暗幕/inert、侧栏偏好与横向溢出。
- 修复浏览器发现的旧 CSS 优先级冲突、手机推荐列表高度上限造成的说明重叠、折叠 details 内不可见按钮进入焦点循环的问题。
- 记忆改为按需挂载后，旧组件断言失败；更新为检查“未打开不挂载、打开后显示”，完整重跑通过。
- 连续四尺寸的初次完整旅程触发生产 API 每分钟 100 次限流，返回会话时失败。保留失败日志，验收脚本为 API 请求设置 800ms 间隔，所有 HTTP 错误也计入最终失败；没有清零限流计数或提高线上限制。

本地复测过程中并行构建替换了静态 hash 文件，导致运行中的旧页面请求 404；该次检查已停止并保留日志。最终固定构建后重新验收，不将这次中断计为通过。降速脚本也改为先等待会话就绪，再断言外壳状态，避免将认证与请求排队时间误判成布局缺失。

公网首轮还发现页面仍引用缺失的 Vite 默认图标（404）；已补上与品牌一致的方桌图标并替换入口引用，保留原失败日志。

冻结布局构建后，本地 1920/1440/768/390 四尺寸完整旅程通过，`errors=[]`，含两主题、三类主抽屉及设置→记忆切换，结果保存在 `local-frozen/report.json`。随后仅修正入口图标引用及新增品牌 SVG；最新部署版公网四尺寸完整旅程同样通过，`errors=[]`，结果保存在 `public-final/report.json`。已人工查看公网桌面明暗主题及手机截图；这不代替用户视觉签收。
