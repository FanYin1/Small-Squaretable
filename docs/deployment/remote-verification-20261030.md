2026-10-30（香港时间），接续用户“验证在实际环境中的访问情况与功能”。入口为 http://47.116.114.103/ ，对应 EXP-02 / EXP-07D 的部署验证；不代替真实模型、多轮机制或人工真机签收。

## 已修复并上线

1. **公网 HTTP 白屏**：服务端 CSP 无条件加入 `upgrade-insecure-requests`，浏览器将脚本和样式升级到尚未配置的 HTTPS。现在只在公开 `APP_URL` 为 HTTPS 时加入，反向代理场景仍保留保护，不根据请求伪造的转发头决定。
2. **私人库加载超时**：13 张工程账户卡片的列表响应解压后为 10,854,012 字节，原 Nginx 未压缩 JSON。启用 JSON/JavaScript/CSS/SVG gzip 后，线上传输为 2,761,489 字节，一次实测 6.415 秒；对照未压缩为 26.382 秒，会超过前端 15 秒超时。现在实际浏览器加载成功，但尚未精简 API 的完整卡片数据，不能承诺弱网下始终及时完成。
3. **选择开局后无法创建故事**：公网 HTTP 下 `crypto.randomUUID` 不存在，创建请求尚未发出就抛错，却显示“创建结果暂时无法确认”。新增统一请求 ID 工具，缺少该 API 时用 `crypto.getRandomValues` 生成 v4 UUID，不使用弱随机数。故事创建、发送消息、纠正分支、附件、适配请求和管理充值请求统一使用此工具，保持原有幂等 ID 语义。

最终镜像：`small-squaretable:remote-20261030-http-ready`，ID 前缀 `3a7c3b10c364`。基于本轮服务端修复镜像 `small-squaretable:remote-20261030-http-csp`（`594dfce6f7a9`），更新客户端产物；远端应用健康、就绪接口 200。只重建 app，数据库及 Redis 不重建、不迁移 schema；本机 3081 未同步升级。

## 失败历史与尚未覆盖

- 第一次进入开局只等待了 1.5 秒，截图停留在加载状态；延长到真实加载完成后出现 10 个选项，这不是开局为空的证据。
- 首次真实创建流程失败于 HTTP 缺少 UUID API，保留原报告；修复部署后从头创建成功，不以 API 绕过页面冒充成功。
- API 测试工具首次未带租户头，返回 400；补租户头后再分别验证 200/401/404。这是检查工具修正，不是生产接口改动。
- **真实供应商回复、流式完成、每轮回复后的推荐、计费及后台记忆在本轮尚未验证**。工程付费调用应经共享预算入口预留及核销；当前生产配置没有账户级工程网关路由，不能把整站模型配置改指测试网关或停正常记忆队列。未绕过账本发起生产付费请求，也未将连接成功记为生成成功。后续需先提供不影响正常用户的工程调用计量路径，再做真实轮次验收。
- 私人列表仍传完整 `cardData` 与内嵌图片，后续应精简列表接口/缩略图；gzip 解决本次现场超时，不关闭所有性能问题。
- 公开入口仍为 HTTP，未配置域名/HTTPS；本轮 UUID 修复没有使安全上下文专属功能自动可用。人工视觉、手机真机、长程连续性及复杂卡片规则仍开放。
