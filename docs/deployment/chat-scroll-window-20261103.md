# 长回复滚动后出现空白的修复

对应DEC-31、INV-04/08。用户截图显示向上滚动后下方长回复消失并留下大片空白。

## 原因和修复

旧虚拟列表先从首个可见消息向前回退5条作为缓冲，再从缓冲起点累计“屏幕高度+固定1000px”来决定末尾。若缓冲里有长回复，累计高度提前耗尽，真正落在屏幕中的后续消息会被卸载成底部占位。因此消息还在数据中，显示范围却不覆盖视口；与控制JSON校验是独立问题。

改为按消息累计偏移分别确定真实视口起点和终点，最后再对两端增加缓冲；单条消息内部的滚动距离不会被忽略。日期分隔线移入对应的测量行，计入完整行高度，列表前的提示和容器内边距用真实起点偏移换算。使用ResizeObserver测量行完整高度，并注册组件挂载前已存在的消息元素；容器和窗口变化时更新视口，未显示的零高测量不会污染缓存。

保留虚拟化和分页，不加载全部故事，不修改消息、推荐、模型调用或剧情状态；本项没有实施此前提出的正文/控制解耦方案。
